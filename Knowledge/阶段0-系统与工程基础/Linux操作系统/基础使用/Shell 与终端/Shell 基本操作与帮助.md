# Shell 基本操作与帮助

## 引入

Linux 中有很多命令，选项和参数也很多。真正高效的使用方式不是把所有命令背下来，而是先看懂一条命令，再知道去哪里查帮助。

本课围绕三个日常问题展开：一行命令由什么组成？不知道选项时怎么办？刚才执行过的命令如何快速找回来？

## 核心内容

### 读懂一行命令

命令行通常可以抽象为：

```text
命令 [选项] [参数]
```

例如：

```bash
ls -l /tmp
```

- `ls` 是命令，表示查看目录内容。
- `-l` 是选项，用来改变显示方式。
- `/tmp` 是参数，表示要查看的对象。

方括号表示这一部分可能是可选的，不要把方括号本身输入到终端。不同命令的语法会有差异，但先区分“命令、选项、参数”，就能读懂大多数常见用法。

选项常见两种写法：

```bash
ls -a
ls --all
```

这两条命令通常表示同一个意思。短选项便于快速输入，长选项更容易读懂；是否支持某个选项，要以该命令的帮助信息为准。

### 执行命令时看什么

输入命令并按下 Enter 后，Shell 会执行它。接下来主要观察三件事：

1. 命令是否成功执行。
2. 是否产生了输出。
3. 是否出现错误信息。

成功执行不一定会有输出。有些命令完成工作后只会重新显示提示符。遇到错误时，先完整阅读错误信息，通常可以从中看出命令名称、路径或参数哪里有问题。

不要把提示符一起复制进命令。例如下面的 `$` 只是提示符：

```text
$ pwd
```

实际输入的只有：

```bash
pwd
```

### 使用 `--help` 快速查选项

许多 Linux 命令支持 `--help`：

```bash
ls --help
```

帮助信息通常会告诉你：

- 命令的基本用法。
- 支持哪些选项。
- 每个选项的作用。
- 命令需要什么参数。

当你只想确认某个选项怎么用时，优先查看 `--help`，通常比搜索完整文档更快。

### 使用 `man` 查看完整说明

`man` 是 Linux 中常用的命令手册入口。例如：

```bash
man ls
```

手册内容通常比 `--help` 更完整，适合了解命令的详细行为。进入手册后：

- 按空格向下翻页。
- 使用方向键上下移动。
- 按 `/` 搜索关键词。
- 按 `q` 退出手册。

可以先看命令的 `SYNOPSIS` 和 `DESCRIPTION`，再根据需要查看 `OPTIONS`。不必一开始从头读到尾。

并不是所有命令都完全支持相同的帮助形式。如果 `--help` 不可用，可以尝试 `man`；如果命令本身没有独立手册，则需要查看对应 Shell 或软件的文档。

### 使用历史记录和补全

命令行提供了两个很实用的功能。

使用上、下方向键，可以找回最近执行过的命令；使用：

```bash
history
```

可以查看历史命令。不同 Shell 对 `history` 后面的数字参数解释可能不同：Bash 中的 `history 5` 通常表示最近 5 条，而 Zsh 中通常表示从历史编号 5 开始显示到末尾；某些 Zsh 配置还会把 `history` 改成自定义函数。因此，不要把 `history 5` 当成跨 Shell 查看最近 5 条记录的通用写法。

命令较多时，按 `Ctrl-R` 可以搜索历史记录，输入关键词后选择需要的命令。

输入命令或路径的开头后按 Tab，Shell 通常会尝试自动补全。补全可以减少输入错误，也能帮助你确认当前目录下有哪些可用名称。

## 示例：从帮助中找到并使用一个选项

下面的过程不要求提前记住 `-a` 的含义：

1. 先查看 `ls` 的帮助。
2. 在帮助信息中找到 `-a` 或 `--all`。
3. 使用这个选项查看当前目录，包括通常隐藏的条目。

```bash
ls --help
ls -a
```

这就是命令行中常见的工作方式：先用帮助确认用法，再执行具体操作。

## 小结（掌握范围）

本课必须掌握：

- 能区分命令、选项和参数，知道提示符不是命令的一部分。
- 知道短选项和长选项的基本区别，并通过帮助确认用法。
- 会使用 `--help` 快速查看命令说明。
- 会使用 `man` 查看完整手册，并用 `q` 退出。
- 会用方向键、`history` 或 `Ctrl-R` 找回历史命令。
- 会使用 Tab 补全命令和路径。

## 课后小实操

### 实操一

使用命令帮助查找选项，再查看当前目录中的隐藏条目。这个操作在排查配置文件、`.git` 目录或其他隐藏文件时很有用。

**操作步骤**

```bash
ls --help
ls -a
```

帮助信息较长时，只需要重点寻找包含 `-a` 或 `--all` 的说明；运行结果主要粘贴第二条命令 `ls -a` 的输出。

### 实操二

练习使用方向键和历史搜索，避免重复输入一条已经执行过的命令。

**操作步骤**

```bash
printf 'history practice\n'
```

执行后按一次上方向键，观察 Shell 是否找回上一条命令，再按 Enter 重新执行它。然后按 `Ctrl-R`，输入 `history practice`，观察 Shell 是否能搜索到刚才的命令；按 Esc 退出搜索即可。这个练习只使用方向键和搜索功能，不依赖不同 Shell 对 `history` 数字参数的不同解释。

**运行结果**

```text
❯ printf 'history practice\n'
history practice
❯ printf 'history practice\n'
history practice
❯ printf 'history practice\n'
bck-i-search: histo_
```

**概括**

按上下方向键可以遍历历史的命令，CTRL+R可以搜索，减少重复命令的打印。
