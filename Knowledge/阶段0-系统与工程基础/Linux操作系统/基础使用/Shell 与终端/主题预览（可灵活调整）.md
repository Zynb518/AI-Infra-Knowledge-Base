我建议“Shell 与终端”先控制在 7 篇左右，并把 TTY/PTY 放到中后段。推荐顺序如下：

```text
Shell 与终端/
├── 终端、Shell 与命令行.md
├── Shell 基本操作与帮助.md
├── 路径与常用文件操作.md
├── Shell 如何解析一条命令.md
├── 标准输入输出、重定向与管道.md
├── 环境变量、PATH 与退出状态.md
├── 前台后台、作业控制与信号.md
└── TTY、PTY 与交互式会话.md
```

各篇可以这样定位：

1. `终端、Shell 与命令行.md`
    
    只建立整体认识：
    ```text
    终端窗口 → Shell → 命令
    ```
    
    解释终端模拟器、Shell、命令、提示符分别是什么。TTY/PTY 这里只简单提一句，不展开。
    
2. `Shell 基本操作与帮助.md`
    
    学会看懂并执行一条命令：
    
    - 提示符
    - 命令、参数和选项
    - `man`
    - `--help`
    - 命令历史
    - Tab 补全
3. `路径与常用文件操作.md`
    
    学习命令行中的基本移动和操作：
    
    - 当前目录、绝对路径、相对路径
    - `pwd`、`ls`、`cd`
    - `~`、`.`、`..`
    - `mkdir`、`cp`、`mv`、`rm`
4. `Shell 如何解析一条命令.md`
    
    解释 Shell 在执行前做了什么：
    
    - 空格和命令分词
    - 引号与转义
    - 通配符
    - 变量展开
    - 命令替换
5. `标准输入输出、重定向与管道.md`
    
    这是 Shell 的核心能力：
    
    - stdin、stdout、stderr
    - `>`、`>>`、`<`
    - `2>`、`2>&1`
    - 管道 `|`
    - `tee`
6. `环境变量、PATH 与退出状态.md`
    
    解释命令为什么能被找到，以及命令是否成功：
    
    - Shell 变量与环境变量
    - `export`
    - `PATH`
    - `$?`
    - `env`
    - `&&`、`||`
7. `前台后台、作业控制与信号.md`
    
    在理解进程之前，先掌握日常操作：
    
    - 前台与后台
    - `&`
    - `Ctrl-C`
    - `Ctrl-Z`
    - `jobs`、`fg`、`bg`
    - `kill`
8. `TTY、PTY 与交互式会话.md`
    
    这篇放后面再讲：
    
    - 终端模拟器和 Shell 的连接
    - `/dev/pts/0`
    - TTY 与 PTY 的区别
    - SSH 是否分配伪终端
    - 为什么管道中会出现 `not a tty`
