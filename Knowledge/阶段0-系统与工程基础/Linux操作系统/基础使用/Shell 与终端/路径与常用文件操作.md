# 路径与常用文件操作

## 引入

Shell 总是在某个目录中工作。你输入 `ls`、创建文件或运行脚本时，如果没有明确写出路径，Shell 通常会以“当前目录”为参照。

很多命令行问题并不是命令本身写错了，而是当前所在目录不对、路径写错，或者把文件和目录混在了一起。本课先掌握路径的基本表示方式，再学习日常最常用的文件操作。

## 核心内容

### 当前目录与 `pwd`

当前目录也叫“工作目录”，表示当前 Shell 正在什么位置。

使用下面的命令查看：

```bash
pwd
```

`pwd` 的意思是 print working directory，即“打印当前工作目录”。在执行文件操作前先确认 `pwd`，是一个很好的习惯，尤其是在远程服务器上操作时。

### 绝对路径与相对路径

路径主要有两种写法。

绝对路径从根目录 `/` 开始，例如：

```text
/var/log/system.log
```

无论当前目录在哪里，这个路径都指向同一个位置。

相对路径不从 `/` 开始，而是以当前目录为参照，例如：

```text
notes/today.md
```

如果当前目录是 `/home/student`，它实际指向 `/home/student/notes/today.md`。换到其他目录后，同一个相对路径可能指向完全不同的位置。

Linux 路径区分大小写，`notes.md` 和 `Notes.md` 可能是两个不同的文件。

### 路径中的特殊位置

下面几个写法非常常见：

| 写法 | 含义 |
| --- | --- |
| `/` | 根目录 |
| `~` | 当前用户的主目录 |
| `.` | 当前目录 |
| `..` | 当前目录的父目录 |
| `-` | 在 `cd -` 中表示上一次所在的目录 |

例如：

```bash
cd ~
cd .
cd ..
cd -
```

`cd .` 通常不会改变位置；`cd ..` 会返回上一级目录；`cd -` 会在最近使用过的两个目录之间切换。

### 查看目录内容：`ls`

`ls` 用来列出目录内容：

```bash
ls
ls -l
ls -a
```

- `ls`：查看当前目录中的可见项目。
- `ls -l`：以详细格式显示，包括权限、所有者、大小和时间等信息。
- `ls -a`：同时显示以 `.` 开头的隐藏项目。

也可以直接查看指定目录：

```bash
ls /tmp
ls -l /var/log
```

不写路径时，`ls` 默认查看当前目录；写出路径后，查看对象由路径决定。

### 切换目录：`cd`

`cd` 用来改变当前 Shell 的工作目录：

```bash
cd /tmp
cd ..
cd ~
```

`cd` 成功后通常不会输出任何内容。可以配合 `pwd` 验证是否切换成功：

```bash
cd /tmp
pwd
```

如果目标目录不存在，Shell 会显示错误信息，当前目录通常不会改变。

### 创建和操作文件

常用的创建和文件操作命令如下：

```bash
mkdir project
touch project/README.md
cp project/README.md project/README.backup.md
mv project/README.backup.md project/README.old.md
```

- `mkdir`：创建目录。
- `touch`：创建空文件；如果文件已经存在，通常只更新时间戳，不会清空内容。
- `cp`：复制文件或目录。
- `mv`：移动或重命名文件、目录。

`mv old.txt new.txt` 在同一个目录中使用时，通常就是重命名。

删除操作要格外谨慎：

```bash
rm file.txt
rmdir empty-directory
```

`rm` 删除文件，`rmdir` 只能删除空目录。命令行通常没有回收站，删除前必须确认路径和文件名。初学时不要随意使用 `rm -rf`，因为它可能递归删除大量内容。

## 示例：先确认位置，再操作文件

下面是一套安全的工作顺序：

```bash
pwd
ls -la
cd /tmp
pwd
cd -
pwd
```

先用 `pwd` 确认位置，再用 `ls -la` 查看内容；切换到 `/tmp` 后再次确认；最后用 `cd -` 返回刚才的目录。

这个顺序看似简单，但在服务器、容器或多个终端窗口中非常有用，可以减少“文件明明存在却找不到”或“操作了错误目录”的问题。

## 小结（掌握范围）

本课必须掌握：

- 会使用 `pwd` 查看当前工作目录。
- 能区分绝对路径和相对路径。
- 理解 `/`、`~`、`.`、`..` 和 `cd -` 的含义。
- 会使用 `ls` 查看目录，知道 `-l` 和 `-a` 的基本作用。
- 会使用 `cd` 切换目录，并用 `pwd` 验证结果。
- 知道 `mkdir`、`touch`、`cp`、`mv`、`rm` 和 `rmdir` 的基本用途。
- 删除前会确认目标路径，不随意使用具有递归删除效果的命令。
