# Shell 与终端

[返回基础使用](../基础使用.md)

## 主题说明

Shell 是本主题的学习主线，终端是人与 Shell 交互的界面。本主题从认识命令行开始，逐步学习基本操作、路径、命令解析、标准输入输出、环境变量、退出状态、作业控制、信号以及 TTY/PTY。

本页是“Shell 与终端”主题的中心入口，只链接已经创建的课程。后续课程实际创建后，再加入这里。

## 学习路径

