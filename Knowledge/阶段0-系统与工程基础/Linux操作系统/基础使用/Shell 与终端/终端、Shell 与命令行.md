# 终端、Shell 与命令行

## 引入

每天输入 `ls`、`cd` 或 `git` 时，我们通常只看到一个终端窗口，很容易把“终端”“Shell”和“命令”当成同一个东西。实际上，它们各自负责不同的工作。

把这几个概念分清，后面学习路径、管道、环境变量和进程时，才知道一条命令到底是谁接收、谁解释、谁执行。

## 核心内容

### 终端窗口是什么

你看到的黑色或白色窗口，通常是“终端模拟器”。它是一个普通的应用程序，主要负责：

- 接收键盘输入。
- 在窗口中显示字符。
- 把输入交给 Shell。
- 把程序输出显示出来。

常见的终端模拟器包括 GNOME Terminal、Konsole、iTerm2 和 Windows Terminal。

终端模拟器本身通常不理解 `cd`、管道或变量。它更像一个负责输入和显示的窗口。

### Shell 是什么

Shell 也是一个程序，但它专门负责理解和执行命令。常见的 Shell 有 Bash、Zsh、Dash 和 Fish。

Shell 启动后通常会显示一个提示符，例如：

```text
user@computer:~$
```

你在提示符后输入命令，Shell 会读取这一行内容，判断要执行什么，然后启动相应的操作。命令结束后，Shell 再次显示提示符，等待下一条命令。

因此，终端窗口是“输入和显示的界面”，Shell 是“理解命令的程序”。打开终端窗口后，系统通常会自动在里面启动一个 Shell，所以两者看起来像是一个整体。

### 命令行是什么

命令行就是我们输入给 Shell 的一行文本。例如：

```bash
ls -l /var/log
```

可以这样看：

- `ls` 是命令，表示查看目录内容。
- `-l` 是选项，要求使用更详细的格式显示。
- `/var/log` 是参数，表示要查看的目录。
- 行首的 `$` 或其他提示符不是命令的一部分，不需要复制输入。

按下 Enter 后，Shell 才会开始处理这一行命令。

### 一条命令是怎样运行的

先记住下面这个简化过程：

```text
键盘输入
    ↓
终端模拟器接收输入
    ↓
Shell 读取并理解命令
    ↓
Shell 执行内建命令，或启动外部程序
    ↓
程序产生输出
    ↓
终端模拟器显示输出
```

例如输入 `ls` 时，Shell 找到并启动 `ls` 程序，`ls` 负责读取目录信息并输出结果，终端窗口负责把结果显示出来。

并不是所有命令都是独立的外部程序。`cd`、`export` 和 `alias` 通常是 Shell 内建命令；`ls`、`ps` 和 `git` 通常是外部程序。

`cd` 必须由当前 Shell 自己执行，因为改变目录只对当前进程有效。如果 Shell 启动一个子进程去执行 `cd`，子进程改变目录后就结束了，原来的 Shell 目录不会改变。

本课只建立终端、Shell 和命令之间的整体关系。引号、变量展开、重定向和管道等更细的处理规则，分别在后续课程中展开。

## 示例：读懂一行命令

```bash
ls -l /tmp
```

这条命令的执行过程可以概括为：

1. 终端模拟器接收你输入的字符。
2. Shell 读取 `ls -l /tmp`。
3. Shell 找到 `ls` 程序，并把 `-l` 和 `/tmp` 交给它。
4. `ls` 读取 `/tmp` 目录并生成输出。
5. 终端窗口显示 `ls` 返回的结果。

## 小结（掌握范围）

本课必须掌握：

- 终端模拟器负责接收输入和显示输出。
- Shell 是负责理解和执行命令的程序。
- 命令行是输入给 Shell 的一行文本，通常由命令、选项和参数组成。
- `cd` 等 Shell 内建命令与 `ls`、`ps` 等外部程序的执行方式不同。

## 课后小实操

### 实操一

观察当前环境中的 Shell，并区分一个 Shell 内建命令和一个外部程序。这个练习可以帮助你在排查命令行为或远程环境问题时，先确认当前使用的 Shell 以及命令的来源。

**操作步骤**

```bash
printf '默认 Shell: %s\n' "$SHELL"
printf '当前 Shell 进程: '
ps -p "$$" -o comm=
printf 'cd: '
command -V cd
printf 'ps: '
command -V ps
```

其中 `$SHELL` 表示默认 Shell，`$$` 表示当前 Shell 的进程号。变量的具体展开规则将在后续课程中详细说明，本次可以先直接运行并观察结果。

**运行结果**

```text
❯ printf 'default shell: %s\n' "$SHELL"
default shell: /usr/bin/zsh
❯ printf 'current shell progress: '
current shell progress: %                                                        ❯ ps -p "$$" -o comm=
zsh
❯ command -V cd
cd is a shell builtin
❯ command -V ps
ps is /usr/bin/ps

```

**概括**

我当前使用的 Shell 是zsh，`cd` 和 `ps` 分别属于内建命令和外部命令，以及终端模拟器负责读取输入和显示输出，Shell 负责读取，理解和执行命令，命令负责执行具体的逻辑。
Zsh 会用 % 标记上一条输出没有换行。
