# chown、chgrp 与所有权

## 引入

前两课分别学习了权限位如何决定“能做什么”，以及 `chmod` 如何修改这些权限位。本课看另外两个字段：文件由哪个用户拥有、属于哪个组。

改变所有者或所属组不会直接改写 `rwx` 权限串，但会影响系统为当前用户选中所有者权限、组权限还是 other 权限。因此，看到访问结果变化时，也要检查所有权。

## 核心内容

### `chown` 和 `chgrp` 分别修改什么

在 `ls -l` 的输出中，权限串之后通常先显示所有者，再显示所属组。`chown` 用来修改所有者；`chgrp` 用来修改所属组。

常见写法可以读作：

- `chown 用户名 文件名`：把文件所有者改成指定用户。
- `chgrp 组名 文件名`：把文件所属组改成指定组。
- `chown 用户名:组名 文件名`：同时指定所有者和所属组。

这些命令修改的是所有权字段，不是 `rwx` 权限位。修改后可以用 `ls -l` 查看新的所有者和所属组。

### 所有权如何影响访问判断

沿用上一课的判断顺序：如果当前用户是文件所有者，系统使用所有者权限；否则，如果当前用户属于文件的所属组，系统使用组权限；两者都不满足时，才使用 other 权限。

因此，即使 `rwx` 权限串没有变化，改变所有者或所属组也可能让某个用户从一组权限切换到另一组权限。`id -nG` 可以帮助确认当前用户是否属于文件所属组。

### 谁可以修改所有权

普通用户通常只能把自己拥有的文件改到自己所属的某个组，因此拥有该文件并且属于目标组时，可以使用 `chgrp`。普通用户通常不能把文件所有者改成另一个用户；更改所有者一般需要管理员权限。

本课的实操只练习 `chgrp`，目标限定为当前用户所属的组，不使用 `sudo`，也不修改其他人的文件。`chown` 的作用和权限要求先理解即可。

## 示例

假设 `permission-demo.txt` 是当前用户自己创建的文件，且当前用户属于 `adm` 组。可以把文件所属组改为 `adm`，然后查看结果：

```bash
chgrp adm permission-demo.txt
ls -l permission-demo.txt
```

示意输出：

```text
-rw-r----- 1 ubzy adm 12 Sep 23 10:00 permission-demo.txt
```

这里所有者仍是 `ubzy`，所属组变成 `adm`，权限串仍是 `rw-r-----`。如果当前用户不属于 `adm`，就不能照搬这个组名；应先用 `id -nG` 查看自己实际所属的组。

## 小结（掌握范围）

本课必须掌握：

- 会从 `ls -l` 输出中找到文件所有者和所属组。
- 知道 `chown` 用来修改所有者，`chgrp` 用来修改所属组。
- 知道所有权字段变化不会直接修改 `rwx` 权限串，但可能改变当前用户匹配到的权限组。
- 知道普通用户通常只能把自己拥有的文件改到自己所属的组。
- 知道修改文件所有者通常需要管理员权限，本课练习不使用管理员权限。
- 会在修改后用 `ls -l` 检查所有者和所属组。

## 课后小实操

### 实操一

在临时位置创建自己拥有的文件，观察只改变所属组时所有权信息如何变化，并恢复文件的原所属组。

**操作步骤**

在 `/tmp` 下确认一个自己命名的练习目录尚未被使用，再创建目录和练习文件。先记录文件原来的所有者与所属组；再从 `id -nG` 显示的组中选择一个不同于文件原所属组、且当前用户确实属于的组，把文件切换到该组并查看结果；最后恢复文件原来的所属组并再次检查。

先把创建练习对象、查询身份、修改所属组、检查并恢复所需的命令写入代码区，再执行并记录真实输出。只操作自己新建的文件，不使用管理员权限，不改变文件所有者。

**代码**

```bash
touch /tmp/main.cpp && ls -l /tmp/main.cpp
id -Gn
chgrp sudo /tmp/main.cpp
ls -l /tmp/main.cpp
chgrp ubzy /tmp/main.cpp 
ls -l /tmp/main.cpp
```

**运行结果**

```text
❯ touch /tmp/main.cpp && ls -l /tmp/main.cpp
-rw-rw-r-- 1 ubzy ubzy 0  9月 23 18:43 /tmp/main.cpp
❯ id -Gn
ubzy adm cdrom sudo dip plugdev users lpadmin sambashare libvirt kvm
❯ chgrp sudo /tmp/main.cpp
❯ ls -l /tmp/main.cpp
-rw-rw-r-- 1 ubzy sudo 0  9月 23 18:43 /tmp/main.cpp
❯ chgrp ubzy /tmp/main.cpp
❯ ls -l /tmp/main.cpp
-rw-rw-r-- 1 ubzy ubzy 0  9月 23 18:43 /tmp/main.cpp

```
