# 用户组与组成员关系

## 引入

Linux 权限判断不仅会看当前用户，还会看当前用户属于哪些组。一个文件可能允许“所有者”访问，也可能允许“所属组”中的成员访问。

上一课确认了当前用户的 UID 和 GID。本课继续回答：

- 主组和附加组有什么区别？
- 如何查看用户所属的所有组？
- 如何查看一个组的 GID 和成员？

本课仍然只进行只读查询，不修改用户组关系。

## 核心内容

### 主组和附加组

使用 id 查看当前身份：

~~~bash
id
~~~

其中：

- gid 表示当前用户的主组。
- groups 中列出的组包含主组和附加组。

主组是用户的默认组。用户创建文件时，文件通常会继承当前用户的主组。附加组则表示用户额外加入的组，访问某些组拥有的资源时会用到。

使用下面的命令分别查看数字信息：

~~~bash
id -g
id -G
~~~

- id -g：只显示主组 GID。
- id -G：显示全部组的 GID。

使用 -n 可以把数字 ID 转换成名称：

~~~bash
id -gn
id -nG
~~~

- id -gn：显示主组名称。
- id -nG：显示全部组名称。

### 使用 groups 查看组名

groups 用于快速显示当前用户所属的组：

~~~bash
groups
~~~

也可以查询指定用户：

~~~bash
groups root
~~~

groups 主要面向人阅读；如果需要同时查看 UID、GID 和组信息，使用 id 更完整。

### 查询组记录

getent group 可以查询系统中的组记录：

~~~bash
getent group sudo
~~~

结果通常由冒号分隔：

~~~text
sudo:x:27:ubzy
~~~

字段含义是：

1. 组名。
2. 组密码字段，通常显示为 x。
3. GID。
4. 直接列出的组成员用户名。

组记录中的成员列表不一定完整表示所有关系。用户的主组关系通常记录在用户信息中，因此判断一个用户是否属于某个组时，应该结合 id 或 groups 一起观察。

### 查询当前用户的组记录

可以先取得当前用户的主组名称，再查询这个组的记录：

~~~bash
primary_group=$(id -gn)
getent group "$primary_group"
~~~

这里的命令替换先取得主组名称，再把名称作为 getent 的参数。整个过程只读取系统信息。

### 用户组和权限的关系

当前用户属于某个组，并不意味着所有文件都允许这个组访问。还要继续查看文件的所属组和权限位。

因此，权限排查通常需要同时回答两个问题：

1. 当前用户属于哪些组？
2. 目标文件允许所属组做什么？

本课只回答第一个问题，文件的所有者、所属组和权限位将在后续课程中学习。

## 示例：比较主组和全部组

下面的命令同时输出当前用户的主组和全部组：

~~~bash
printf 'primary group: %s (%s)\n' "$(id -gn)" "$(id -g)"
printf 'all groups: %s\n' "$(id -nG)"
~~~

如果主组名称也出现在全部组名称中，这是正常现象，因为主组属于用户的全部组集合。

## 小结（掌握范围）

本课必须掌握：

- 知道用户有一个主组，也可以属于多个附加组。
- 会使用 id -g 和 id -G 查看主组及全部组的 GID。
- 会使用 id -gn 和 id -nG 查看主组及全部组名称。
- 会使用 groups 快速查看用户所属组。
- 会使用 getent group 查询组名、GID 和成员记录。
- 知道组成员关系只是权限判断的一部分，还要结合文件所有者、所属组和权限位。
- 能区分主组和附加组的基本用途。

## 课后小实操

### 实操一

制作一份当前用户的组关系记录，比较主组、全部组和系统组记录。

**操作步骤**

不要修改任何用户或组配置，根据课堂中的 id、groups 和 getent group 完成以下要求：

- 输出当前用户的主组名称和主组 GID。
- 输出当前用户的全部组名称和全部组 GID。
- 使用当前用户的主组名称查询对应的组记录。
- 输出中使用清晰的字段名称。
- 将实际命令写入代码区，再执行并记录结果。

**代码**

~~~bash
printf 'main group: id=%s, name=%s \n' "$(id -g)" "$(id -gn)"
printf 'groups: \n ids=%s \n names=%s \n' "$(id -G)" "$(id -Gn)"
primary_group=$(id -gn)
printf 'group record=%s\n' "$(getent group "$primary_group")"
~~~

**运行结果**

~~~text
❯ printf 'main group: id=%s, name=%s \n' "$(id -g)" "$(id -gn)"
main group: id=1000, name=ubzy 
❯ printf 'groups: \n ids=%s \n names=%s \n' "$(id -G)" "$(id -Gn)"
groups: 
 ids=1000 4 24 27 30 46 100 105 125 128 993 
 names=ubzy adm cdrom sudo dip plugdev users lpadmin sambashare libvirt kvm 
❯ primary_group=$(id -gn)
❯ printf 'group record=%s\n' "$(getent group $primary_group)"
group record=ubzy:x:1000:

~~~
