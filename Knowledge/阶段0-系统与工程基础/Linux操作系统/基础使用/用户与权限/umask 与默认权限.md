# umask 与默认权限

## 引入

新建文件或目录时，权限通常不是随机决定的。系统会从创建程序请求的基础权限中去掉一部分权限，这个“要去掉哪些位”的设置叫 `umask`。

理解 `umask` 可以解释为什么新文件和新目录一创建就有不同权限，也能帮助我们在不反复运行 `chmod` 的情况下控制新对象的默认权限。本课只在独立练习目录中创建新对象，不改动已有文件。

## 核心内容

### 新建对象的基础权限

常见情况下，创建普通文件时程序请求的基础权限是 `666`，即 `rw-rw-rw-`；创建目录时请求的基础权限是 `777`，即 `rwxrwxrwx`。文件默认基础权限不包含执行位，目录则需要 `x` 才能经过和访问。

实际权限由基础权限和 `umask` 一起决定。`umask` 只影响之后新建的对象，不会改变已经存在的文件或目录；已有对象的权限要用 `chmod` 修改。

### 把 umask 看成权限位图

可以继续使用上一课的位图理解方式。`umask` 中为 `1` 的位会从创建程序请求的权限中屏蔽掉：

```text
最终权限 = 创建程序请求的权限 AND NOT umask
```

例如，掩码 `022` 中，所有者位没有屏蔽，组和其他用户的写位被屏蔽。对普通文件：

```text
基础权限 666：110 110 110
umask   022：000 010 010
最终权限 644：110 100 100
```

对目录，同一个掩码会得到：

```text
基础权限 777：111 111 111
umask   022：000 010 010
最终权限 755：111 101 101
```

所以相同的 `umask` 用在文件和目录上，结果不同：文件的基础权限没有 `x`，目录的基础权限有 `x`。这是按位屏蔽，不是把三个数字做普通的十进制减法。

### 查看和临时设置 umask

单独运行 `umask` 可以查看当前 Shell 的掩码；不同 Shell 可能显示三位或四位八进制数，本课关注表示 `rwx` 的后三位。

运行 `umask 027` 会把当前 Shell 的掩码临时设为 `027`。它不会改动已有对象，也不会直接写入系统全局配置；当前 Shell 及它启动的程序会使用这个值，直到再次修改或 Shell 结束。

在交互式 Shell 中临时试验前，可以先记录原值，结束后恢复：

```bash
old_umask=$(umask)
umask 027
# 在这里创建并检查新的练习对象
umask "$old_umask"
```

这段代码先用命令替换保存原值，最后把原值交还给 `umask`。如果把这些命令写进脚本执行，掩码变化只在该脚本进程及其子进程中有效；脚本退出后不会改变启动它的终端 Shell。

## 示例

查看当前掩码时，输出可能类似：

```bash
umask
```

```text
0022
```

若将当前 Shell 的掩码临时设置为 `022`，之后新建的普通文件常见权限为 `644`，新建目录常见权限为 `755`。可以用 `ls -l` 查看文件，用 `ls -ld` 查看目录本身；实际结果也取决于创建程序请求的基础权限。

## 小结（掌握范围）

本课必须掌握：

- 知道普通文件和目录常见的创建基础权限分别是 `666` 和 `777`。
- 知道 `umask` 会屏蔽新建对象的权限位，不影响已有对象。
- 能用位图解释基础权限如何经过 `umask` 得到最终权限。
- 会用 `umask` 查看当前掩码，并知道设置值会影响当前 Shell 后续创建的对象。
- 能在临时试验后恢复原来的 `umask`，并区分交互式 Shell 与脚本进程的作用范围。

## 课后小实操

### 实操一

观察一个不同于课堂示例的掩码如何影响新建文件和新建目录。

**操作步骤**

在 `/tmp` 下确认一个自己命名的练习目录尚未被使用，再创建该目录。先记录当前 `umask`；随后在当前 Shell 中临时设置掩码 `027`，在练习目录中新建一个普通文件和一个子目录，并查看两者的权限。最后恢复原掩码，再查看一次当前掩码，确认已经恢复。

比较文件与目录的权限结果，分别从基础权限 `666`、`777` 和位图屏蔽的角度解释。

**代码**

```bash
old_umask=$(umask)
umask 027
mkdir -p /tmp/directory && touch /tmp/main.cpp
ls -ld /tmp/directory && ls -l /tmp/main.cpp
umask "$old_umask"
umask

```

**运行结果**

```text
❯ old_umask=$(umask)
❯ umask 027
❯ mkdir /tmp/directory && touch /tmp/main.cpp
❯ ls -ld /tmp/directory && ls -l /tmp/main.cpp
drwxr-x--- 2 ubzy ubzy 4096  9月 23 19:36 /tmp/directory
-rw-r----- 1 ubzy ubzy 0  9月 23 19:36 /tmp/main.cpp
❯ umask "$old_umask"
❯ umask
002

```
