# ACL 的概念与 getfacl

## 引入

传统权限把访问者分成所有者、所属组和其他用户三类。如果需要“只让某个指定用户读取文件，但不改变整组或其他人的权限”，这三组权限表达起来就不够细。

ACL（访问控制列表）可以在传统权限之外，为指定用户或组增加访问条目。本课先学习读取和理解 ACL，不修改任何权限。

## 核心内容

### ACL 增加了哪些对象

一个 ACL 可以包含以下类型的条目：

| 条目 | 控制对象 |
|---|---|
| `user::` | 文件所有者 |
| `user:用户名:` | 指定用户 |
| `group::` | 文件所属组 |
| `group:组名:` | 指定组 |
| `mask::` | 限制组权限类别中可生效的最大权限 |
| `other::` | 不匹配其他条目的用户 |

每个条目仍然使用 `rwx` 表示读、写和执行/搜索权限。ACL 不会改变文件的所有者或所属组，只是增加更细的访问规则。

### 用 getfacl 查看 ACL

`getfacl` 显示文件名、所有者、所属组以及 ACL 条目：

```bash
getfacl report.txt
```

如果对象没有额外 ACL，通常只看到所有者、所属组和其他用户对应的基础条目。若出现指定用户或组的条目，则表示 ACL 提供了更细的访问设置。目录还可能显示 `default:` 开头的默认 ACL，用于影响之后新建的子对象；默认 ACL 会在后续课程中单独学习。[getfacl(1)](https://man7.org/linux/man-pages/man1/getfacl.1.html)

### 理解 ACL mask 和有效权限

ACL 中的 `mask::` 是组权限类别的上限。它会限制指定用户、指定组和文件所属组条目实际能使用的权限，但不限制文件所有者条目 `user::` 或 `other::`。

例如，某个组条目写着 `rw-`，而 mask 是 `r-x`，该组实际只能读，不能写。`getfacl` 在条目后显示 `#effective:r--` 时，表示条目原本列出的权限被 mask 收窄了。

检查 ACL 时，可按这个顺序思考：

1. 当前用户是文件所有者时，看 `user::`。
2. 否则，若有匹配的指定用户条目，看该 `user:用户名:` 条目，并受 mask 限制。
3. 否则，检查当前用户所属的组条目；匹配的组权限合并后受 mask 限制。
4. 没有匹配的用户或组条目时，看 `other::`。

命中指定用户条目后，如果该条目经 mask 限制仍不满足访问请求，系统会拒绝访问，不会继续退回组条目或 `other::`。这仍然是按身份类别选择权限，不会把所有者、指定用户、组和 other 的权限任意相加。[acl(5)](https://man7.org/linux/man-pages/man5/acl.5.html)

### ACL 与 ls -l 的关系

如果文件或目录有扩展 ACL，`ls -l` 通常会在权限串后显示 `+`，例如：

```text
-rw-r-x---+ 1 ubzy team ... report.txt
```

这个 `+` 提醒你还有 ACL 条目，单看九个 `rwx` 位不足以看清完整规则。存在 ACL mask 时，`ls -l` 的组权限位对应 mask，而不一定等于 `group::` 条目本身。[acl(5)](https://man7.org/linux/man-pages/man5/acl.5.html)

## 示例

下面是一个示意 ACL：

```text
# file: report.txt
# owner: ubzy
# group: team
user::rw-
user:alice:r--
group::rw-        #effective:r--
group:reviewers:r-x
mask::r-x
other::---
```

文件所有者 `ubzy` 使用 `rw-`。指定用户 `alice` 有 `r--`。所属组条目原本是 `rw-`，但 mask 是 `r-x`，因此实际权限是 `r--`；`reviewers` 组实际可读和搜索/执行。`other::---` 表示没有匹配到其他条目的用户没有权限。

`ls -l` 中的组权限显示为 `r-x`，并带有 `+`：组权限位反映 mask，`+` 表示需要继续用 `getfacl` 查看完整条目。

## 小结（掌握范围）

本课必须掌握：

- 知道 ACL 可以为指定用户和组添加比 owner/group/other 更细的访问条目。
- 会用 `getfacl` 查看基础 ACL、指定用户/组条目和目录默认 ACL。
- 知道 mask 会限制指定用户、指定组和所属组条目的有效权限。
- 能解释 `getfacl` 中的 `#effective:` 注释。
- 知道 `ls -l` 权限串后的 `+` 提示存在需要进一步查看的 ACL。
- 能按所有者、指定用户、匹配组和 other 的顺序分析访问权限。
