# chmod 与数字权限

## 引入

上一课我们学会了从 `ls -l` 输出中读出权限。这一课学习如何在安全的练习对象上设置权限，并把 `rwx` 三组权限转换成三个数字。

权限修改会直接影响文件或目录的访问方式，所以只对自己新建的练习对象操作，不拿系统文件、课程笔记或已有的重要文件做练习。

## 核心内容

### 用 chmod 设置权限

`chmod` 用于修改文件或目录的权限位。数字模式由三位组成，顺序固定为：

```text
所有者   所属组   其他用户
  第1位    第2位     第3位
```

数字模式会把所有者、所属组和其他用户的权限设为指定状态，不是只追加某个权限。修改后可以用 `ls -l` 查看文件权限，或用 `ls -ld` 查看目录权限。

### 把 rwx 换成数字

可以把每一组权限看成三个开关位，顺序是 `rwx`：某项权限存在时该位为 `1`，不存在时为 `0`。

```text
权限位： r w x
权值：   4 2 1
```

因此 `rw-` 是二进制 `110`，对应数字 6；`r-x` 是二进制 `101`，对应数字 5。每组三位可以压缩写成一个八进制数字，因为每一位的权值分别是读 `r=4`、写 `w=2`、执行或访问 `x=1`。

三个数字合起来就是九个权限位。例如 `640₈` 展开为 `110 100 000₂`：

```text
110  100  000
│    │    └── 其他用户：---
│    └─────── 所属组：r--
└──────────── 所有者：rw-
```

把每组中为 `1` 的位对应权限相加，就得到该组的数字。

| 数字 | 权限组合 | 计算方式 |
|---:|:---:|:---|
| 0 | `---` | 无权限 |
| 1 | `--x` | 1 |
| 2 | `-w-` | 2 |
| 3 | `-wx` | 2 + 1 |
| 4 | `r--` | 4 |
| 5 | `r-x` | 4 + 1 |
| 6 | `rw-` | 4 + 2 |
| 7 | `rwx` | 4 + 2 + 1 |

所以 `640` 拆成三位后，分别是所有者 `6`（读和写）、所属组 `4`（读）和其他用户 `0`（无权限）。权限串最前面的文件类型标记，例如普通文件的 `-`，不包含在这三个数字里。

目录也可以用同样的数字方法设置权限，不过每组中的 `x` 表示可以经过或搜索目录，不是运行目录。修改后用 `ls -ld` 查看目录自身的权限串。

### 谁有权修改权限

通常，文件或目录的所有者可以修改自己的权限；管理员也可以修改。练习时使用当前用户自己创建的文件或目录即可，不需要管理员权限。如果遇到“权限被拒绝”，先确认练习对象是否由当前用户创建，不要立即尝试提升权限。

## 示例

假设 `permission-demo.txt` 是自己新建的临时练习文件。要让所有者可读写、所属组可读、其他用户无权限，可以把三组权限分别换算后设置，再查看结果：

```bash
chmod 640 permission-demo.txt
ls -l permission-demo.txt
```

示意输出如下，用户名、组名、大小和时间会因环境而不同：

```text
-rw-r----- 1 alice developers 12 Sep 23 10:00 permission-demo.txt
```

权限串中的 `rw-r-----` 与数字 `640` 对应：所有者是 `rw-`，所属组是 `r--`，其他用户是 `---`。关键是先按“所有者、所属组、其他用户”的顺序分别计算三位，再检查显示的权限串；若结果不同，应先检查数字顺序和每组的加和值。

## 小结（掌握范围）

本课必须掌握：

- 知道 `chmod` 用于修改文件或目录的权限位。
- 知道数字权限的三位依次表示所有者、所属组和其他用户。
- 会按 `r=4`、`w=2`、`x=1` 计算单组权限，并能解释 0 到 7 的组合。
- 知道数字模式会设置这三组权限，而不是只追加权限。
- 会用 `ls -l` 或 `ls -ld` 检查权限修改后的结果。
- 只对自己创建的练习文件或目录修改权限，不为练习使用管理员权限。

## 课后小实操

### 实操一

在临时位置创建一个专用练习目录，再根据权限目标计算数字并设置权限。

**操作步骤**

在 `/tmp` 下选择一个自己命名的全新目录，先确认该名称尚未被使用，再创建它。目标是：目录所有者可以列出目录、经过目录并修改其中的条目；所属组成员可以列出目录并经过目录，但不能修改目录条目；其他用户没有目录权限。

把创建目录、设置权限和查看目录权限所需的命令先写入代码区，再执行并记录真实输出。根据 `ls -ld` 的结果解释三组权限。不要操作已有目录、课程笔记或系统文件，也不要使用管理员权限。

**代码**

```bash
mkdir -p  /tmp/directory
ls -ld /tmp/directory
chmod 750 /tmp/directory
ls -ld /tmp/directory
```

**运行结果**

```text
❯ mkdir -p  /tmp/directory
❯ ls -ld /tmp/directory
drwxrwxr-x 2 ubzy ubzy 4096  9月 23 15:11 /tmp/directory
❯ chmod 750 /tmp/directory
❯ ls -ld /tmp/directory
drwxr-x--- 2 ubzy ubzy 4096  9月 23 15:11 /tmp/directory

```
