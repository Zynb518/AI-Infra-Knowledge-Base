# 文件所有者、所属组与权限位

## 引入

上一课我们确认了当前用户属于哪些组。现在继续看一个文件：谁拥有它、它属于哪个组，以及不同身份分别能读、写或执行什么。

这些信息是排查“为什么我能读这个文件，却不能修改它”一类问题的基础。本课只练习查看和判断，不修改文件的权限或所有权。

## 核心内容

### 查看文件的所有者和所属组

使用 `ls -l` 查看文件的详细列表：

```bash
ls -l /etc/hosts
```

输出的一行中，权限信息后面的两个名称分别是文件所有者和所属组。例如：

```text
-rw-r--r-- 1 nobody nogroup 229 Aug 26 13:24 /etc/hosts
```

这里 `nobody` 是所有者，`nogroup` 是所属组。大小和修改时间等字段也会显示出来，但本课先关注所有者、所属组和最左侧的权限串。具体名称、大小和时间会随系统环境变化。

### 读懂最左侧的权限串

权限串的第一个字符表示对象类型，后面的九个字符按三位一组排列：

```text
- rw- r-- r--
  │   │   └── 其他用户（other）
  │   └────── 所属组成员（group）
  └────────── 所有者（user）
```

- 为了看清分组，示意中加了空格；`ls` 输出里的字符是连续的。这里先认识两种常见类型：`-` 表示普通文件，`d` 表示目录。
- `r` 表示读，`w` 表示写，`x` 表示执行或访问，`-` 表示没有对应权限。
- 三组权限依次属于所有者、所属组成员和其他用户。

因此 `-rw-r--r--` 表示：所有者可读写，所属组成员可读，其他用户也可读；三组都没有执行权限。

### Linux 如何选择适用的一组权限

判断当前用户时，按以下顺序选择一组权限：

1. 如果当前用户就是文件所有者，使用第一组权限。
2. 否则，如果当前用户属于文件的所属组，使用第二组权限。
3. 否则，使用第三组权限，也就是 other。

只使用匹配到的那一组，不会把所有者权限和组权限拼在一起。上一课的 `id -nG` 可以查看当前用户所属的组；把它和 `ls -l` 显示的所有者、所属组对照，就能判断当前身份会落在哪一组。

### 文件和目录上的权限含义

对普通文件：

- `r` 允许读取文件内容。
- `w` 允许修改文件内容。
- `x` 允许尝试执行该文件。

对目录，权限控制的是目录本身：

- `r` 允许列出目录中的名称。
- `w` 允许增删或重命名目录中的条目；通常还需要 `x` 才能实际访问这些条目。
- `x` 允许进入目录，或通过目录中的名称访问对象。

所以目录的 `x` 不是“运行这个目录”。文件自身的权限与所在目录的权限也各自独立；访问一个带路径的文件时，路径上的目录还需要允许用户经过。

想查看目录本身的权限，用 `ls -ld`：

```bash
ls -ld /etc
```

如果只对目录执行 `ls -l`，看到的是目录里的内容；加上 `-d` 后，显示的是目录这一项。

## 示例

下面分别查看一个文件和一个目录：

```bash
ls -l /etc/hosts
ls -ld /etc
```

示例输出：

```text
-rw-r--r-- 1 nobody nogroup 229 Aug 26 13:24 /etc/hosts
drwxr-xr-x 157 nobody nogroup 12288 Sep 21 13:54 /etc
```

第一行以 `-` 开头，表示普通文件。所有者 `nobody` 有 `rw-`，所属组 `nogroup` 和其他用户分别有 `r--`。如果当前用户既不是 `nobody`，也不属于 `nogroup`，就看第三组权限，因此可以读这个文件，但不能通过权限位修改或执行它。

第二行以 `d` 开头，表示目录。`drwxr-xr-x` 中，目录所有者有 `rwx`；所属组成员和其他用户有 `r-x`，可以列出名称并经过目录，但没有修改目录条目的 `w` 权限。

## 小结（掌握范围）

本课必须掌握：

- 会用 `ls -l` 查看文件的所有者、所属组和权限串。
- 会用 `ls -ld` 查看目录本身，而不是目录中的内容。
- 能读出权限串首字符表示的类型，以及后面三组 `rwx` 权限。
- 能结合当前用户和 `id -nG` 的结果，判断应使用所有者、所属组还是 other 权限。
- 能解释 `r`、`w`、`x` 用在普通文件和目录上的基本含义。
- 知道文件权限和所在目录权限分别生效，访问路径还需要经过路径上的目录。

## 课后小实操

### 实操一

检查一个系统文件和它所在的目录，练习把当前身份与文件权限对应起来。

**操作步骤**

使用 `/etc/passwd` 作为文件对象、`/etc` 作为目录对象。分别查看文件和目录本身的长格式信息，然后完成以下记录：

- 标出文件类型、所有者、所属组和三组权限。
- 使用上一课的身份查询结果，分别判断当前用户对文件和目录应匹配哪一组权限。
- 说明这些权限对文件内容、目录列表和路径访问分别意味着什么。
- 只依据显示出的权限位进行判断，不修改文件或目录。

**代码**

```bash
❯ ls -l /etc/passwd && ls -ld /etc
```

**运行结果**

```text
❯ ls -l /etc/passwd && ls -ld /etc
-rw-r--r-- 1 root root 3070  9月  8 11:03 /etc/passwd
drwxr-xr-x 157 root root 12288  9月 21 13:54 /etc

文件类型：普通文件 和 目录
所有者：都是root
所属组：都是root
权限：rw-r--r-- 和 rwxr-xr-x
我们不是root用户也不是root组的，因此我们的权限为 r-- 和 r-x 
我们对文件只读，我们对目录可读可执行
```
