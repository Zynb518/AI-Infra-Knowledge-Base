# 安装、更新与卸载的安全操作

## 引入

APT 安装或卸载一个包时，可能连同依赖包一起变更。更新软件时还要区分“刷新可用包信息”和“真正升级已安装包”。本课把安装、更新与卸载放在同一条操作流程中：先确认目标和计划，再执行必要的变更，最后核对结果。

上一阶段已经完成 `htop` 的安装模拟。本课保留那份实操记录，并继续围绕 `htop` 练习小范围的真实操作。

## 核心内容

### 先查询，再模拟变更

`apt-cache policy 包名` 显示本机已安装版本和 APT 候选版本。`apt-get -s` 中的 `-s` 表示模拟：只展示根据当前状态预计发生的操作，不安装或删除软件包。[apt-get(8)](https://manpages.debian.org/bookworm/apt/apt-get.8.en.html)

例如：

```bash
apt-get -s install tree
apt-get -s remove tree
```

模拟输出中的 `Inst` 是预计安装或解包，`Conf` 是预计配置，`Remv` 是预计移除。它们是计划，不是执行结果。检查新增、升级和卸载清单时，要把依赖包也算在操作范围内。模拟基于当时的本机状态与软件包索引，之后状态变化时应重新核对。

### 安装指定包并验证

`sudo apt install 包名` 会实际安装目标包及所需依赖，可能要求确认。确认提示出现时，核对包名及新增、升级、卸载数量；若清单与预期不同，先结束该次操作并重新检查计划。[apt(8)](https://manpages.debian.org/bookworm/apt/apt.8.en.html)

安装完成后，`dpkg-query -s 包名` 中的 `Status: install ok installed` 表示包已安装；`apt-cache policy 包名` 的 `Installed` 显示本机登记的版本。对 `htop`，`htop --version` 会输出程序版本并退出。[dpkg-query(1)](https://manpages.debian.org/bookworm/dpkg/dpkg-query.1.en.html) [htop(1)](https://github.com/htop-dev/htop/blob/main/htop.1.in)

### 更新索引与升级软件

`sudo apt update` 从已配置的软件源刷新本机软件包索引，不会把已安装程序升级到新版本。`sudo apt upgrade` 则会实际升级符合条件的已安装包，操作范围可能覆盖系统中的许多软件包。[apt(8)](https://manpages.debian.org/bookworm/apt/apt.8.en.html)

如果只想观察某个已安装包的候选更新，可以先查看 `apt-cache policy 包名`，再用 `apt-get -s install 包名` 模拟对该包的安装或升级。上一课的 `coreutils` 曾出现仓库版本高于已安装版本；本课只观察其更新计划，不实际升级该基础包。

刷新索引后，候选版本和后续安装计划可能改变。应以刷新后的查询和模拟结果决定下一步。

### 卸载目标包并检查影响

`sudo apt remove 包名` 会卸载指定包，通常保留包管理器管理的配置文件；`sudo apt purge 包名` 还会清除这类配置。`sudo apt autoremove` 会考虑清除不再需要的自动安装依赖，因此执行前也要逐项查看清单。[apt(8)](https://manpages.debian.org/bookworm/apt/apt.8.en.html)

卸载前先用 `apt-get -s remove 包名` 查看预计移除哪些包。实际卸载后，用 `apt-cache policy 包名` 检查 `Installed` 是否变为 `(none)`。`dpkg-query -s` 可能仍显示配置文件残留状态，所以不能只凭它是否还能查到记录判断软件仍已安装。

## 示例

假设 `tree` 是自己想测试的小工具，下列只读命令分别预览安装和卸载计划：

```bash
apt-cache policy tree
apt-get -s install tree
apt-get -s remove tree
```

如果 `tree` 尚未安装，安装模拟可能列出 `Inst tree` 和 `Conf tree`；如果它没有安装，卸载模拟可能显示无事可做。实际输出由当前系统状态决定。完成计划核对后，才对自己明确选择的目标使用对应的真实 `apt` 操作。

## 小结（掌握范围）

本课必须掌握：

- 会在包变更前查看候选版本并模拟安装或卸载，读懂 `Inst`、`Conf`、`Remv`。
- 知道 `apt install` 安装目标及必要依赖，安装后会核对本机状态和版本。
- 能区分 `apt update` 刷新索引与 `apt upgrade` 升级已安装软件。
- 知道可以模拟观察单个已安装包的候选更新，不必为练习执行全系统升级。
- 会在卸载前确认移除清单，并区分 `remove`、`purge` 和 `autoremove` 的作用。
- 知道操作前后的系统状态或索引变化会使先前的模拟计划失效。

### 实操二

围绕 `htop` 完成一次有核对、有验证的安装与卸载，并观察软件更新计划。

**操作步骤**

先确认 `htop` 当前是否已安装。刷新软件包索引后，重新查看候选版本和安装模拟；如果计划仍只包含预期变更，再安装 `htop`，随后核对包状态、安装版本与命令版本。对先前出现过候选更新的 `coreutils`，仅模拟查看当前的单包更新计划。

接着模拟卸载 `htop`。只有确认它是本次实操新安装的，而且卸载计划只涉及预期对象时，才实际卸载并核对结果。如果刷新索引失败、计划发生意外变化或实际操作报错，记录输出并停在已完成的步骤。不要执行全系统升级、`purge`、`autoremove`，也不要使用自动确认选项。

先把准备使用的命令写入代码区，再逐条执行；在每个实际变更的确认提示处停下来检查清单，最后填写真实输出。不要整段一键运行。

**代码**

```bash
apt-cache policy htop
sudo apt update
apt-cache policy htop
apt-get -s install htop
sudo apt install htop
apt-cache policy coreutils
apt-get -s install coreutils

apt-get -s remove htop
sudo apt remove htop 
apt-cache policy htop
```
