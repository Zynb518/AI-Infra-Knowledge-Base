# 软件包、软件仓库与依赖关系

## 引入

在 Linux 上安装软件时，通常不是手动把一个程序文件复制到某个目录，而是让包管理工具安装一个软件包。软件包带有程序文件和描述这些文件的元数据；它还可能依赖其他软件包才能正常工作。

理解软件包、仓库和依赖，可以帮助我们判断软件从哪里来、安装时为什么会带上其他包，以及如何先查询再决定是否安装。

## 核心内容

### 软件包是安装和管理的单位

一个软件包通常包含程序、配置模板、文档等文件，以及包名、版本、架构和依赖关系等元数据。包名与命令名不一定一一对应：一个包可以提供多个命令，命令名也不一定就是包名。

安装一个包不等于相关服务已经启动。例如，软件包可以安装一个服务程序，但是否正在运行、是否开机启动，需要另行检查和管理。

### 软件仓库提供软件包和目录信息

软件仓库由发行版或软件维护者发布，包含可供包管理器查找的软件包版本和元数据。APT 会读取本机保存的软件包索引，据此展示当前已知的包信息，并在安装时从配置的软件仓库取得所需内容。

仓库索引里的信息和本机已安装的软件状态是两个概念。查询到一个可用版本，不代表该包已经安装；本机索引过旧时，显示的可用版本也可能不是仓库当前最新版本。

### 依赖描述软件包之间的需要关系

软件包可能需要其他包提供共享库、命令或运行环境。这些关系叫依赖。包管理器可以根据依赖信息，计算安装一个目标包时还需要哪些其他包。

`Depends` 通常列出目标包的直接依赖；一个直接依赖本身还可能依赖更多软件包。安装或卸载时应先查看包管理器准备执行的操作，避免只关注命令本身而忽略受影响的其他包。

### 用 apt show 查看包信息

`apt show` 可以查看 APT 当前索引中某个软件包的描述信息：

```bash
apt show bash
```

重点观察 `Package`、`Version`、`Depends` 和 `Description` 等字段。这个查询用于查看元数据，不会安装、更新或卸载软件。

## 示例

查看 Bash 软件包：

```bash
apt show bash
```

输出节选示意如下，版本号和依赖会随 Linux Mint 版本及本机软件源而变化：

```text
Package: bash
Version: <版本号>
Depends: <直接依赖列表>
Description: GNU Bourne Again SHell
```

`Package` 是包名，`Version` 是该索引记录的版本，`Depends` 展示直接依赖，`Description` 是包的简短说明。输出说明 APT 认识这个包，不单独证明它已安装。

## 小结（掌握范围）

本课必须掌握：

- 知道软件包是包管理器安装和管理软件的单位。
- 知道仓库提供软件包和元数据，本机索引记录 APT 当前已知的信息。
- 能用直白语言解释软件包依赖的作用。
- 会用 `apt show` 查看包名、版本、直接依赖和说明。
- 知道查询到的仓库版本不等于本机已安装状态，安装软件包也不等于启动相关服务。

## 课后小实操

### 实操一

查看一个常用基础工具的软件包信息，区分包说明、版本和依赖。

**操作步骤**

选择 `coreutils` 软件包进行查询。记录输出中的包名、版本、直接依赖和描述，并用一句话说明“依赖”字段告诉你什么。只执行查询，不安装、更新或卸载软件。

先把查询命令写入代码区，再执行并填写真实输出。如果本机索引中没有该包信息，记录实际提示即可，不要为了完成练习更新索引或安装软件。

**代码**

```bash
apt show coreutils
```

**运行结果**

```text
Package: coreutils
Version: 9.4-3ubuntu6.3
Priority: required
Essential: yes
Section: utils
Origin: Ubuntu
Maintainer: Ubuntu Developers <ubuntu-devel-discuss@lists.ubuntu.com>
Original-Maintainer: Michael Stone <mstone@debian.org>
Bugs: https://bugs.launchpad.net/ubuntu/+filebug
Installed-Size: 7,111 kB
Pre-Depends: libacl1 (>= 2.2.23), libattr1 (>= 1:2.4.48), libc6 (>= 2.38), libgmp10 (>= 2:6.3.0+dfsg), libselinux1 (>= 3.1~), libssl3t64 (>= 3.0.0)
... 
Description: GNU 核心工具包

```

这些字段告诉了我包名 coreutils，版本 9.4-3ubuntu6.3，必须安装，依赖 libacl1 (>= 2.2.23), libattr1 (>= 1:2.4.48), libc6 (>= 2.38), libgmp10 (>= 2:6.3.0+dfsg), libselinux1 (>= 3.1~), libssl3t64 (>= 3.0.0)。 描述 GNU 核心工具包
