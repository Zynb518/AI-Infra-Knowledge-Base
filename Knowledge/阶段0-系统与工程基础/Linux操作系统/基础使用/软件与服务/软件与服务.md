# 软件与服务

[返回基础使用](../基础使用.md)

## 主题说明

本主题学习 Linux 软件包如何安装和管理，以及后台服务如何由系统启动、停止和保持运行。重点是理解软件包、运行中的程序和系统服务之间的关系，并能先检查状态，再判断需要采取什么操作。

本主题是 Linux“基础使用”的一部分；学习内容从本机只读查询开始，再逐步练习软件包和服务管理。

## 学习范围

- 软件包、软件仓库和依赖关系的基本概念。
- 使用 `apt` 查询软件、查看包信息、安装、更新和卸载软件。
- 使用 `dpkg` 查询本机已安装的软件包及其文件。
- systemd 服务与 unit 的基本概念。
- 使用 `systemctl` 查看服务状态、启动、停止、重启服务。
- 区分服务当前是否运行（active）与是否设置为开机启动（enabled）。
- 根据服务状态信息进行初步检查，并验证管理操作的结果。

## 建议学习顺序

~~~text
软件包、仓库与依赖
        ↓
apt 与 dpkg 的职责
        ↓
软件包查询与安装状态
        ↓
安装、更新与卸载的安全操作
        ↓
进程、后台服务与 systemd unit
        ↓
systemctl 服务状态与生命周期
        ↓
active 与 enabled 的区别
        ↓
服务操作后的验证
~~~

## 学习约定

- 先用只读命令确认软件包和服务的当前状态。
- 安装、更新、卸载或更改服务状态前，确认目标和操作影响。
- 示例优先使用本机已有的软件包和服务，不为练习安装额外软件。
- 课后实操采用题目模式，涉及系统变更时只操作明确指定且必要的目标。

## 已创建课程

1. [软件包、软件仓库与依赖关系](<./软件包、软件仓库与依赖关系.md>)

   认识软件包和软件仓库，并用 `apt show` 查看软件包元数据和直接依赖。

2. [APT 与 dpkg 的职责](<./APT 与 dpkg 的职责.md>)

   学习区分 APT 的仓库与依赖管理职责，以及 dpkg 对本机已安装软件包的管理职责。

3. [软件包查询与安装状态](<./软件包查询与安装状态.md>)

   学习区分本机已安装版本、APT 候选版本和软件源提供的版本记录。

4. [安装、更新与卸载的安全操作](<./安装、更新与卸载的安全操作.md>)

   学习核对 APT 变更计划，区分刷新索引与升级软件，并验证指定软件包的安装和卸载结果。
