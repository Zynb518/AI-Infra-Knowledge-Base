# Bash 脚本

## 主题说明

本主题承接“Shell 与终端”和“常用命令与文本处理”，系统学习如何把一组命令整理成可重复执行、可维护、可排错的 Bash 脚本。

学习重点不是记住大量语法，而是建立一条完整思路：

~~~text
接收输入 → 处理数据 → 判断结果 → 重复执行 → 组织复用 → 处理异常
~~~

本主题会从“如何运行一个最简单的脚本”开始，逐步学习变量、引用、参数、条件判断、循环、数组、函数和调试方法。每一课只引入少量新概念，并配合有实际意义的本地实操。

本主题聚焦 Bash 脚本的日常编写和维护，不展开讲解其他编程语言、Shell 内部实现、复杂部署系统或大型工程框架。

## 学习路径

~~~text
脚本文件与执行方式
        ↓
变量、引用与字符串
        ↓
位置参数、用户输入与输出
        ↓
命令替换与退出状态
        ↓
条件判断：if、test 与 case
        ↓
循环：for、while 与批量处理
        ↓
数组与多项数据处理
        ↓
函数、局部变量与脚本组织
        ↓
重定向、管道与临时文件
        ↓
调试、错误处理与安全习惯
        ↓
综合实战：文件处理、日志分析与系统检查
~~~

学习过程中会反复使用前置主题中的 `find`、`grep`、`sort`、`sed`、`awk`、`tar` 等命令，但重点会放在“如何在脚本中可靠地组织它们”。

## 已创建课程

1. [脚本文件与执行方式](<./脚本文件与执行方式.md>)

   学习 Bash 脚本的基本结构、shebang、使用 bash 执行脚本，以及通过可执行权限直接运行脚本。

2. [变量、引用与字符串](<./变量、引用与字符串.md>)

   学习 Bash 变量的定义与展开、单引号和双引号的区别，以及变量在路径和命令参数中的安全使用。

3. [位置参数、用户输入与输出](<./位置参数、用户输入与输出.md>)

   学习使用位置参数接收命令行输入，使用 read 读取交互输入，并用 printf 输出处理结果。

4. [命令替换与退出状态](<./命令替换与退出状态.md>)

   学习保存命令输出、读取退出状态，并使用 && 和 || 连接成功或失败后的动作。

5. [条件判断：if、test 与 case](<./条件判断：if、test 与 case.md>)

   学习使用 test、if 和 case 根据文件、字符串、数字及固定模式选择不同的脚本分支。

6. [循环：for、while 与批量处理](<./循环：for、while 与批量处理.md>)

   学习使用 for 遍历参数和列表，使用 while 按条件重复或逐行读取文件，并结合条件判断完成批量处理。

7. [数组与多项数据处理](<./数组与多项数据处理.md>)

   学习使用 Bash 索引数组保存多项数据，并结合位置参数、循环和条件判断完成批量处理。

8. [函数、局部变量与脚本组织](<./函数、局部变量与脚本组织.md>)

   学习定义和调用函数、使用 local 管理作用域、返回退出状态，并用 main 组织脚本流程。

9. [重定向、管道与临时文件](<./重定向、管道与临时文件.md>)

   学习在脚本中保存标准输出和错误输出、组合管道、使用 tee，并安全管理临时文件。

10. [调试、错误处理与安全习惯](<./调试、错误处理与安全习惯.md>)

   学习使用 bash -n、bash -x、set -u、pipefail 和 trap 检查脚本、处理失败并清理临时资源。
