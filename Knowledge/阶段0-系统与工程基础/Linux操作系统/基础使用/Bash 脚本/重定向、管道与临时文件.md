# 重定向、管道与临时文件

## 引入

脚本运行时，命令的输出通常显示在终端。但实际工作中，我们经常需要把结果保存成报告、把错误单独记录，或者把一个命令的输出交给下一个命令继续处理。

脚本还可能需要临时保存中间结果。临时文件不能使用固定名称，否则多个脚本同时运行时可能互相覆盖。

本课学习：

- 如何重定向标准输入、标准输出和错误输出。
- 如何在脚本中组合管道和 tee。
- 如何使用 mktemp 创建临时文件，并在使用后删除自己创建的文件。

## 核心内容

### 标准输出和错误输出

命令通常有两类文字输出：

- 标准输出：正常处理结果。
- 标准错误：错误提示和诊断信息。

Bash 使用文件描述符表示它们：

- 1：标准输出。
- 2：标准错误。

不写文件描述符时，重定向符号默认处理标准输出：

~~~bash
printf 'normal output\n' > /tmp/bash-course/output.txt
~~~

如果要单独保存错误输出，使用 2：

~~~bash
file /tmp/not-found > /tmp/bash-course/file-output.txt 2> /tmp/bash-course/file-error.txt
~~~

这样，正常输出进入 file-output.txt，错误信息进入 file-error.txt。

### 覆盖、追加和读取

使用 > 会覆盖目标文件：

~~~bash
printf 'first line\n' > /tmp/bash-course/notes.txt
printf 'new first line\n' > /tmp/bash-course/notes.txt
~~~

第二条命令会覆盖第一条命令写入的内容。

使用 >> 会追加到文件末尾：

~~~bash
printf 'first line\n' > /tmp/bash-course/notes.txt
printf 'second line\n' >> /tmp/bash-course/notes.txt
~~~

使用 < 把文件作为命令的标准输入：

~~~bash
sort < /tmp/bash-course/notes.txt
~~~

重定向只改变输入输出的来源或去向，不会改变命令本身的处理逻辑。

### 同时保存标准输出和标准错误

如果希望把正常输出和错误输出写入同一个文件，可以使用：

~~~bash
command > /tmp/bash-course/all-output.txt 2>&1
~~~

执行顺序是：

1. 把标准输出重定向到 all-output.txt。
2. 把标准错误重定向到当前标准输出的位置，也就是 all-output.txt。

顺序很重要。2>&1 表示“让标准错误跟随当前标准输出”，因此通常写在标准输出重定向之后。

### 使用管道继续处理输出

管道把前一个命令的标准输出连接到后一个命令的标准输入：

~~~bash
printf 'worker\napi\napi\n' | sort -u
~~~

这里 printf 产生文本，sort -u 读取这些文本并完成排序去重。

错误输出默认不会自动进入管道：

~~~bash
file /tmp/not-found | sort
~~~

如果希望把标准输出和错误输出都交给管道，需要先合并：

~~~bash
some_command 2>&1 | sort
~~~

### 使用 tee 同时显示和保存

普通管道会把输出交给下一个命令，终端可能看不到中间结果。tee 可以把输入复制到文件，同时继续输出到终端：

~~~bash
printf 'api\nworker\n' | tee /tmp/bash-course/services.txt
~~~

如果要追加到文件，使用 tee -a：

~~~bash
printf 'database\n' | tee -a /tmp/bash-course/services.txt
~~~

tee 适合生成报告、保留中间结果和观察管道中的实际内容。

### 使用 mktemp 创建临时文件

固定临时文件名可能产生覆盖问题。mktemp 会创建一个唯一的临时文件并输出它的路径：

~~~bash
temporary_file=$(mktemp)
printf 'intermediate data\n' > "$temporary_file"
printf 'temporary path: %s\n' "$temporary_file"
~~~

如果需要临时目录，可以使用：

~~~bash
temporary_dir=$(mktemp -d)
printf 'temporary directory: %s\n' "$temporary_dir"
~~~

临时文件使用完成后，应只删除脚本自己创建的明确路径：

~~~bash
rm -f "$temporary_file"
~~~

本课先使用显式删除完成清理。如何在脚本中无论成功、失败或中断都自动清理，会在后续错误处理与安全主题中学习。

## 示例：生成排序后的服务报告

下面的脚本生成一组服务名，排序去重后，通过 tee 同时显示并保存报告：

~~~bash
#!/usr/bin/env bash

report='/tmp/bash-course/service-report.txt'
printf 'worker\napi\napi\ndatabase\n' | sort -u | tee "$report"
printf 'report: %s\n' "$report"
~~~

命令链负责生成报告内容，tee 负责保存和显示，最后的 printf 告诉调用者报告文件位置。

## 小结（掌握范围）

本课必须掌握：

- 知道标准输出使用文件描述符 1，标准错误使用文件描述符 2。
- 会使用 > 覆盖文件，>> 追加文件，< 从文件读取输入。
- 会使用 2> 单独保存错误输出。
- 会使用 > file 2>&1 合并标准输出和标准错误。
- 会使用管道把一个命令的标准输出交给下一个命令。
- 知道错误输出默认不会自动进入管道。
- 会使用 tee 同时显示并保存输出，知道 tee -a 用于追加。
- 会使用 mktemp 创建唯一临时文件或目录。
- 会在使用完成后只删除自己创建的明确临时路径。

## 课后小实操

### 实操一

创建一个服务报告脚本，把命令行参数排序后保存为报告，同时在终端显示处理结果。

**操作步骤**

创建 /tmp/bash-course/pipeline-report.sh，并完成以下要求：

- 接收任意数量的服务名参数。
- 保留参数中包含空格的服务名。
- 将服务名按字典顺序排序。
- 去掉重复服务名。
- 使用 tee 同时显示结果并保存到 /tmp/bash-course/pipeline-report.txt。
- 脚本最后输出报告文件路径。

可以使用已经学过的 "$@"、printf、sort -u、管道和 tee。不要直接修改报告文件内容。

回到终端执行：

~~~bash
bash /tmp/bash-course/pipeline-report.sh worker api 'test worker' api
~~~

**代码**

~~~bash
#!/usr/bin/env bash

path="/tmp/bash-course/pipeline-report.txt"
printf '%s\n' "$@" | sort -u | tee "$path"
printf 'report path is %s\n' "$path"

~~~

**运行结果**

~~~text
❯ bash /tmp/bash-course/pipeline-report.sh worker api 'test worker' api
api
test worker
worker
report path is /tmp/bash-course/pipeline-report.txt

~~~

### 实操二

创建一个临时文件处理脚本，分别记录正常输出和错误输出，并在处理完成后清理临时文件。

**操作步骤**

创建 /tmp/bash-course/temp-check.sh，并完成以下要求：

- 使用 mktemp 创建一个临时文件，并把路径保存到变量。
- 向临时文件写入至少两行文本。
- 使用 sort 读取临时文件，把正常结果保存到 /tmp/bash-course/temp-output.txt。
- 让一次会产生错误的 file 命令，把错误信息保存到 /tmp/bash-course/temp-error.txt。
- 在脚本结束前删除自己创建的临时文件。
- 最后输出两个报告文件的路径。

可以使用已经学过的 mktemp、printf、sort、file、重定向和 rm -f。不要删除报告文件或其他已有文件。

回到终端执行：

~~~bash
bash /tmp/bash-course/temp-check.sh
~~~

**代码**

~~~bash
#!/usr/bin/env bash

tmp_file="$(mktemp)"
output_path='/tmp/bash-course/temp-output.txt'
error_path='/tmp/bash-course/temp-error.txt'
printf 'hello\nworld\n' > "$tmp_file"
sort -u "$tmp_file" > "$output_path"
file error-path > "$error_path" 2>&1
rm -f "$tmp_file"
printf 'output path: %s\n' "$output_path"
printf 'error path: %s\n' "$error_path"
~~~

**运行结果**

~~~text
❯ bash /tmp/bash-course/temp-check.sh
error-path: cannot open `error-path' (No such file or directory)
output path: /tmp/bash-course/temp-output.txt
error path: /tmp/bash-course/temp-error.txt

~~~
