# 数组与多项数据处理

## 引入

变量适合保存一个值，但脚本经常需要同时管理多个服务名、多个路径或多个处理结果。如果为每个值单独创建变量，代码会变得重复且难以批量处理。

Bash 数组可以把多个值放进同一个变量中，再通过索引、循环和参数展开逐个使用。本课先学习最常用的索引数组，不引入更复杂的关联数组。

## 核心内容

### 创建索引数组

创建数组时，把多个值放在圆括号中，值之间使用空格分隔：

~~~bash
services=(api worker database)
~~~

Bash 数组的索引从 0 开始：

~~~bash
printf 'first: %s\n' "${services[0]}"
printf 'second: %s\n' "${services[1]}"
~~~

数组元素中包含空格时，需要单独引用这个元素：

~~~bash
services=('api gateway' worker)
printf '%s\n' "${services[0]}"
~~~

这里的 api gateway 是一个元素，不是两个元素。

### 获取数组长度和全部元素

使用数组的 @ 展开形式可以取得所有元素，使用 # 可以取得元素数量：

~~~bash
printf 'count: %s\n' "${#services[@]}"

for service in "${services[@]}"; do
  printf 'service: %s\n' "$service"
done
~~~

双引号中的 "${services[@]}" 会把每个数组元素保持为一个独立参数。因此，即使某个元素包含空格，for 仍然会把它作为一个完整项目处理。

不要把数组整体写成未加引号的 ${services[@]}，否则元素中的空格可能被拆分，路径中的通配符也可能发生展开。

### 添加和修改数组元素

使用 += 可以在数组末尾追加元素：

~~~bash
services=(api worker)
services+=(database)
services+=(cache)
~~~

也可以通过索引修改已有元素：

~~~bash
services[1]='batch-worker'
~~~

修改后，数组长度仍然由实际存在的元素决定。

### 从命令行参数创建数组

可以把脚本收到的所有位置参数保存到数组中：

~~~bash
targets=("$@")
printf 'target count: %s\n' "${#targets[@]}"

for target in "${targets[@]}"; do
  printf 'target: %s\n' "$target"
done
~~~

这里使用 "\$@" 的原因是保留每个命令行参数的边界。比如某个路径包含空格，保存到数组后仍然是一个完整元素。("\$@") 保留多个参数；"\$@" 赋值给普通变量时会变成一个字符串。

### 数组和循环结合处理多项数据

数组本身只是数据容器，真正的批量处理仍然需要使用循环：

~~~bash
services=('api gateway' worker database)
services+=(cache)

for service in "${services[@]}"; do
  printf 'checking: %s\n' "$service"
done
~~~

循环变量每次取得一个数组元素，循环体中的命令就可以对这一项执行相同操作。

### 使用数组时的常见注意事项

- 数组索引从 0 开始。
- 数组元素之间使用空格分隔，不使用逗号。
- 元素包含空格时，在数组定义中要单独引用。
- 遍历全部元素时，优先使用 "${array[@]}"。
- 数组长度使用 "${#array[@]}"。
- 直接使用数组元素时，使用 "${array[index]}"。

## 示例：整理并输出服务清单

下面的脚本创建一个服务数组，追加一个服务，然后输出数量和每个服务：

~~~bash
#!/usr/bin/env bash

services=('api gateway' worker database)
services+=(cache)

printf 'service count: %s\n' "${#services[@]}"
for service in "${services[@]}"; do
  printf 'service: %s\n' "$service"
done
~~~

注意，api gateway 虽然包含空格，但在输出中仍然是一项服务。

## 小结（掌握范围）

本课必须掌握：

- 会使用 name=(value1 value2) 创建索引数组。
- 知道数组索引从 0 开始。
- 会使用 "${array[index]}" 读取数组元素。
- 会使用 "${#array[@]}" 获取数组元素数量。
- 会使用 "${array[@]}" 配合 for 遍历全部元素。
- 会使用 array+=(value) 追加元素。
- 会修改指定索引的数组元素。
- 会使用 targets=("$@") 把命令行参数保存为数组。
- 处理包含空格的元素时，会使用双引号保护元素边界。

## 课后小实操

### 实操一

创建一个服务数组脚本，练习创建数组、追加元素、统计数量和保持带空格元素的完整性。

**操作步骤**

创建 /tmp/bash-course/service-array.sh，并完成以下要求：

- 初始数组依次包含 api、test worker、database 三个元素。
- 在数组末尾追加 cache。
- 输出数组总数。
- 使用循环逐行输出每个服务，格式为 service: 服务名。
- 不要为每个服务单独创建变量。

必要提示：使用索引数组语法，使用 += 追加元素，使用数组长度展开统计数量，遍历时使用双引号包围的数组全部元素展开。

回到终端执行：

~~~bash
bash /tmp/bash-course/service-array.sh
~~~

**代码**

```bash
#!/usr/bin/bash

array=(api 'test worker' database)
array+=(cache)
printf 'array length=%s\n' "${#array[@]}"
for service in "${array[@]}"; do
  printf 'service: %s\n' "${service}"
done
```

**运行结果**

~~~text
❯ bash /tmp/bash-course/service-array.sh
array length=4
service: api
service: test worker
service: database
service: cache
~~~

### 实操二

创建一个路径统计脚本，练习把命令行参数保存为数组，并根据每个路径的类型统计数量。

**操作步骤**

创建 /tmp/bash-course/path-summary.sh，并完成以下要求：

- 把全部命令行参数保存到一个数组中。
- 输出收到的路径总数。
- 遍历数组中的每个路径。
- 普通文件、目录和不存在的路径分别计数。
- 最后输出三类数量。
- 处理路径时必须保留包含空格的参数边界。

可以使用已经学过的 -f、-d、if、for、"$@"、数组长度和整数递增。不要修改传入的文件或目录。

回到终端执行：

~~~bash
bash /tmp/bash-course/path-summary.sh /etc/hosts /tmp '/tmp/bash-course/not found'
~~~

**代码**

```bash
#!/usr/bin/env bash

array=("$@")
printf 'total path num=%s\n' "$#"
file_num=0
directory_num=0
unknown=0

for path in "${array[@]}"; do
  if [ -f "$path" ]; then
    file_num=$((file_num+1))
  elif [ -d "$path" ]; then
    directory_num=$((directory_num+1))
  else
    unknown=$((unknown+1))
  fi
done

printf ' file_num=%s \n directory_num=%s \n unknown=%s \n' "$file_num" "$directory_num" "$unknown"
```

**运行结果**

~~~text
❯ bash /tmp/bash-course/path-summary.sh /etc/hosts /tmp '/tmp/bash-course/not found'
total path num=3
 file_num=1 
 directory_num=1 
 unknown=1 
~~~
