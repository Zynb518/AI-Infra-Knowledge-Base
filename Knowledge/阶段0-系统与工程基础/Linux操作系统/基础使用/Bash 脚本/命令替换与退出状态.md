# 命令替换与退出状态

## 引入

脚本不仅要执行命令，还经常需要使用命令产生的结果。例如，先统计文件数量，再把数量写进报告；先检查一个操作是否成功，再决定是否继续。

Bash 用两种不同的信息描述命令执行结果：

- 标准输出：命令打印出来的文字。
- 退出状态：命令执行成功还是失败的状态码。

本课学习如何获取这两种结果，并把它们用于后续命令。

## 核心内容

### 用命令替换保存标准输出

命令替换的写法是美元符号加圆括号：

~~~bash
services=$(printf 'api\nworker\napi\n' | sort -u)
printf 'services:\n%s\n' "$services"
~~~

Bash 会先执行圆括号中的命令，把它产生的标准输出保存到 services 变量中，然后再执行 printf。

命令替换适合把命令输出交给后续的变量、判断或其他命令。使用变量时仍然要加双引号：

~~~bash
result=$(printf 'api request completed')
printf 'result: %s\n' "$result"
~~~

命令替换会去掉命令输出末尾的换行符，但中间的换行会保留：

~~~bash
lines=$(printf 'api\nworker\n')
printf '<%s>\n' "$lines"
~~~

因此，命令替换适合保存文本结果；如果需要保留末尾换行，需要使用其他方式处理，本课暂不展开。

### 退出状态表示成功或失败

每条命令执行结束后，Bash 都会得到一个退出状态。通常：

- 0 表示成功。
- 非 0 表示失败。

特殊参数 $? 表示最近一条命令的退出状态：

~~~bash
true
printf 'true status: %s\n' "$?"

false
printf 'false status: %s\n' "$?"
~~~

true 和 false 是 Bash 中用于返回成功或失败状态的简单命令。它们常用于学习和测试退出状态。

退出状态必须及时保存，因为下一条命令执行后，$? 就会变成下一条命令的状态：

~~~bash
false
status=$?
printf 'saved status: %s\n' "$status"
~~~

如果在 false 和读取 $? 之间先执行了其他命令，就无法再通过 $? 得到 false 的状态。

### 命令替换和退出状态可以同时使用

可以先保存命令输出，再立即保存这条命令的退出状态：

~~~bash
result=$(printf 'operation completed\n')
status=$?

printf 'status: %s\n' "$status"
printf 'result: %s\n' "$result"
~~~

这里的 status 对应的是命令替换所在命令的退出状态。保存状态时不要在中间插入其他命令。

### 使用 && 连接成功后的动作

&& 表示：只有前一个命令成功，才执行后一个命令：

~~~bash
true && printf '前一个命令成功\n'
false && printf '这行不会输出\n'
~~~

常见用途是“操作成功后继续”：

~~~bash
mkdir -p /tmp/bash-course/output && printf 'output directory is ready\n'
~~~

如果 mkdir 成功，printf 才会执行；如果 mkdir 失败，后面的 printf 会被跳过。

### 使用 || 连接失败后的动作

|| 表示：只有前一个命令失败，才执行后一个命令：

~~~bash
true || printf '这行不会输出\n'
false || printf '前一个命令失败，执行备用动作\n'
~~~

常见用途是提供一个简单的失败提示或备用动作：

~~~bash
false || printf 'operation failed\n'
~~~

&& 和 || 适合表达简单的成功/失败关系。更复杂的条件组合会在下一课使用 if、test 和 case 详细学习。

### 命令失败不会自动停止脚本

默认情况下，某条命令失败后，脚本仍然可能继续执行：

~~~bash
false
printf 'script continues\n'
~~~

所以脚本不能只依赖屏幕上的输出判断是否成功。需要根据任务保存退出状态，或者使用后续课程中的条件判断和错误处理方式。

## 示例：统计并报告唯一服务名

下面的脚本先生成一组服务名，使用 sort -u 去重，再保存输出和退出状态：

~~~bash
#!/usr/bin/env bash

services=$(printf 'api\nworker\napi\n' | sort -u)
status=$?

printf 'command status: %s\n' "$status"
printf 'unique services:\n%s\n' "$services"
~~~

这里的 services 是命令输出，status 是命令退出状态。两者解决的是不同问题：前者说明命令产生了什么内容，后者说明命令是否成功完成。

## 小结（掌握范围）

本课必须掌握：

- 会使用 $(...) 保存命令的标准输出。
- 使用命令替换得到的变量时，默认加双引号。
- 知道命令替换会去掉输出末尾的换行。
- 知道退出状态中 0 通常表示成功，非 0 表示失败。
- 会使用 $? 读取最近一条命令的退出状态。
- 知道读取 $? 前不能先执行其他命令。
- 会先保存命令输出，再及时保存对应的退出状态。
- 会使用 && 表示成功后执行，使用 || 表示失败后执行。
- 知道命令失败后脚本默认不一定会自动停止。

## 课后小实操

### 实操一

创建一个脚本，使用命令替换保存去重后的服务名，并输出命令的退出状态和处理结果。

**操作步骤**

创建 /tmp/bash-course/command-result.sh，并将下面的内容写入文件：

~~~bash
#!/usr/bin/env bash

services=$(printf 'api\nworker\napi\ndatabase\n' | sort -u)
status=$?

printf 'status: %s\n' "$status"
printf 'services:\n%s\n' "$services"
~~~

回到终端执行：

~~~bash
bash /tmp/bash-course/command-result.sh
~~~

**运行结果**

~~~text
❯ bash /tmp/bash-course/command-result.sh
status: 0
services:
api
database
worker

~~~

### 实操二

创建一个脚本，分别观察成功命令、失败命令、&& 和 || 的行为。

**操作步骤**

创建 /tmp/bash-course/status-chain.sh，并将下面的内容写入文件：

~~~bash
#!/usr/bin/env bash

true
printf 'true status: %s\n' "$?"

false
status=$?
printf 'false status: %s\n' "$status"

true && printf 'success action\n'
false && printf 'skipped action\n'
false || printf 'fallback action\n'
~~~

回到终端执行：

~~~bash
bash /tmp/bash-course/status-chain.sh
~~~

**运行结果**

~~~text
❯ bash /tmp/bash-course/status-chain.sh
true status: 0
false status: 1
success action
fallback action

~~~
