# 常用命令与文本处理

[返回基础使用](../基础使用.md)

## 主题说明

本主题承接“Shell 与终端”，集中学习 Linux 中用于查看、搜索、统计、整理和转换信息的常用命令，为后续编写 Bash 脚本准备可组合的工具。

学习重点不是孤立背诵命令和选项，而是围绕实际任务选择工具，并通过标准输入输出、重定向和管道把多个命令组合起来。

本主题只讨论命令的日常使用方式，不深入文件系统内部机制、用户权限模型或网络协议；这些内容分别放在对应主题和章节中学习。

## 学习路径

```text
查看文件内容与变化
        ↓
搜索文件和文本
        ↓
统计、排序与去重
        ↓
提取和转换文本
        ↓
查看文件、磁盘与系统信息
        ↓
归档压缩与命令组合
        ↓
为 Bash 脚本准备工具基础
```

## 已创建课程

1. [查看文件内容与变化](<./查看文件内容与变化.md>)

   学习使用 `cat`、`less`、`head`、`tail` 和 `tail -f` 查看文本内容与持续变化。

2. [搜索文件与文本](<./搜索文件与文本.md>)

   学习使用 `find` 查找路径，并使用 `grep` 搜索文件和命令输出中的文本。

3. [统计、排序与去重](<./统计、排序与去重.md>)

   学习使用 `wc`、`sort` 和 `uniq` 完成统计、排序、去重与频次排行。

4. [提取和转换文本](<./提取和转换文本.md>)

   学习使用 `cut`、`tr` 和基础 `sed` 提取字段、转换字符与替换文本。

5. [查看文件、磁盘与系统信息](<./查看文件、磁盘与系统信息.md>)

   学习使用 `file`、`stat`、`df`、`du`、`uname`、`uptime` 和 `free` 收集基础系统信息。

6. [归档、压缩与命令组合](<./归档、压缩与命令组合.md>)

   学习使用 `tar` 创建、查看和解开归档，并通过管道继续处理归档内容。

7. [为 Bash 脚本准备工具基础](<./为 Bash 脚本准备工具基础.md>)

   学习使用命令替换、`&&`、`||`、`tee` 和 `xargs`，把多个常用命令组合成可重复执行的处理流程。
