# 查看文件、磁盘与系统信息

## 引入

排查 Linux 问题时，先收集事实比直接猜原因更重要。我们需要知道文件到底是什么、文件有哪些元数据、磁盘还剩多少空间，以及当前系统和内存处于什么状态。

本课学习一组只读观察命令，并重点区分两组容易混淆的概念：

- `file` 与 `stat`：文件类型和文件元数据。
- `df` 与 `du`：文件系统剩余空间和目录实际占用空间。

## 核心内容

### 用 `file` 判断文件类型

`file` 根据文件内容和特征判断类型，而不是只看扩展名：

~~~bash
file README.md
~~~

结果可能类似：

~~~text
README.md: Unicode text, UTF-8 text
~~~

对于脚本、压缩包、图片或二进制文件，`file` 可以帮助你确认“这个文件实际是什么”，避免只根据文件名猜测。

### 用 `stat` 查看文件元数据

`stat` 查看文件的详细元数据：

~~~bash
stat README.md
~~~

输出通常包括：

- 文件大小。
- 文件类型和权限信息。
- 所有者与所属组。
- inode 编号。
- 访问时间、修改时间和状态改变时间。
- 文件占用的块数。

本课只把 `stat` 当作观察工具，不深入 inode、权限位和时间戳更新规则；这些内容会在后续主题中分别学习。

`file` 回答“文件是什么类型”，`stat` 回答“文件的大小、时间和元数据是什么”。

### 用 `df` 查看文件系统空间

`df` 查看文件所在文件系统的整体空间：

~~~bash
df -h /tmp
~~~

`-h` 表示使用易读单位。输出通常包含：

- 文件系统。
- 总容量。
- 已使用空间。
- 可用空间。
- 使用率。
- 挂载位置。

`df` 回答的是：

> 这个文件系统整体还剩多少空间？

查看根文件系统时可以使用：

~~~bash
df -h /
~~~

磁盘写入失败时，先用 `df -h` 检查空间和使用率是常见排查步骤。

### 用 `du` 查看目录占用

`du` 统计文件和目录实际占用的空间：

~~~bash
du -sh /tmp
~~~

常用选项：

- `-s`：只显示汇总结果。
- `-h`：使用易读单位。

`du` 回答的是：

> 这个目录及其内容占用了多少空间？

如果想查看目录下一层各项目的大小：

~~~bash
du -h --max-depth=1 /tmp
~~~

`df` 和 `du` 的区别可以这样记：

| 命令 | 关注对象 | 典型问题 |
| --- | --- | --- |
| `df` | 整个文件系统 | 磁盘还剩多少空间？ |
| `du` | 某个目录或文件 | 哪些目录占用了空间？ |

两者结果不一定简单相加，例如文件系统保留空间、硬链接或已经删除但仍被进程打开的文件，都可能造成差异。

### 用 `uname` 查看内核和系统

`uname` 查看系统基本信息：

~~~bash
uname -sr
~~~

其中：

- `-s` 显示内核名称。
- `-r` 显示内核版本。

如果希望查看更多信息，可以使用：

~~~bash
uname -a
~~~

`uname` 适合确认当前运行的内核和系统环境。它不等于完整的发行版信息；需要发行版详情时，还要查看对应系统的发行版文件或工具。

### 用 `uptime` 查看运行时间和负载

`uptime` 显示系统运行时间、当前登录用户数量和负载平均值：

~~~bash
uptime
~~~

输出中的 load average 通常会显示 1 分钟、5 分钟和 15 分钟三个时间窗口的平均负载。

本课先把它当成系统是否繁忙的观察线索，不直接用负载数值判断故障。负载需要结合 CPU 数量、I/O 等待和具体进程进一步分析。

### 用 `free` 查看内存

`free` 查看内存和交换空间：

~~~bash
free -h
~~~

常见列包括：

- `total`：总量。
- `used`：已使用量。
- `free`：完全空闲量。
- `buff/cache`：缓冲区和页缓存。
- `available`：系统估计仍可供新程序使用的内存。

判断内存是否紧张时，不要只盯着 `free`；`available` 通常更能反映系统还能否为新程序提供内存。

## 示例：收集一份基础系统信息

下面的命令只读取信息，不修改系统：

~~~bash
printf '内核：\n'
uname -sr

printf '运行时间与负载：\n'
uptime

printf '内存：\n'
free -h

printf '根文件系统空间：\n'
df -h /
~~~

这类信息可以作为排查报告的基础，后续再根据异常指标深入查看进程、I/O 或内核行为。

## 小结（掌握范围）

本课必须掌握：

- 会使用 `file` 判断文件实际类型。
- 会使用 `stat` 查看文件大小、时间和基本元数据。
- 能区分 `df` 查看文件系统整体空间，`du` 查看目录或文件占用空间。
- 会使用 `df -h` 和 `du -sh` 输出易读的空间信息。
- 会使用 `uname -sr` 查看内核名称和版本。
- 会使用 `uptime` 查看系统运行时间和负载平均值。
- 会使用 `free -h` 查看内存，并知道 `available` 的参考意义。
- 能根据排查问题选择文件、磁盘或系统信息命令。

## 课后小实操

### 实操一

创建一个临时文件，分别观察文件类型、文件元数据、文件系统剩余空间和练习目录占用空间。

**操作步骤**

~~~bash
mkdir -p /tmp/system-info-practice
printf 'system information practice\n' > /tmp/system-info-practice/sample.txt

file /tmp/system-info-practice/sample.txt
stat /tmp/system-info-practice/sample.txt
df -h /tmp/system-info-practice
du -sh /tmp/system-info-practice
~~~
