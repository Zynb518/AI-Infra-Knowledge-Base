# 查看文件内容与变化

## 引入

查看配置文件、日志和命令输出是 Linux 中最常见的工作之一。文件很短时可以一次显示，文件很长时需要分页阅读，排查服务问题时还需要持续观察新增日志。

本课学习 `cat`、`less`、`head`、`tail` 和 `tail -f`。重点不是记住更多命令，而是根据“文件大小、查看位置和是否持续变化”选择合适的工具。

## 核心内容

### 先选择合适的查看方式

| 需求 | 推荐命令 |
| --- | --- |
| 显示一个较短文本文件的全部内容 | `cat` |
| 分页阅读较长内容 | `less` |
| 只看开头几行 | `head` |
| 只看末尾几行 | `tail` |
| 持续观察文件末尾新增内容 | `tail -f` |

这些命令默认把内容写到标准输出，因此既可以直接显示在终端，也可以继续交给管道中的其他命令。

### 用 `cat` 显示完整内容

`cat` 会按顺序读取文件，并把内容写到标准输出：

~~~bash
cat README.md
~~~

如果提供多个文件，`cat` 会依次输出它们：

~~~bash
cat part1.txt part2.txt
~~~

`cat` 的名称来自 concatenate，即“连接”。它既能显示单个文件，也能把多个文件内容连接到同一条输出流。

`cat -n` 会在输出中添加行号：

~~~bash
cat -n README.md
~~~

`cat` 适合较短的文本文件。对很长的日志直接使用 `cat`，内容会快速滚过屏幕，不方便阅读，此时应使用 `less`、`head` 或 `tail`。

### 用 `less` 分页阅读

`less` 会打开分页阅读界面：

~~~bash
less README.md
~~~

常用按键包括：

| 按键 | 作用 |
| --- | --- |
| 空格或 PageDown | 向下翻一页 |
| `b` 或 PageUp | 向上翻一页 |
| `/关键词` | 向下搜索 |
| `n` | 跳到下一个匹配 |
| `N` | 跳到上一个匹配 |
| `g` | 回到开头 |
| `G` | 跳到末尾 |
| `q` | 退出 |

`less` 默认不会修改文件，只负责阅读。命令输出很长时，也可以通过管道分页查看：

~~~bash
ls --help | less
~~~

这里 `ls --help` 产生帮助文本，管道把文本交给 `less`。

### 用 `head` 查看开头

`head` 默认显示文件前 10 行：

~~~bash
head README.md
~~~

`-n` 可以指定行数：

~~~bash
head -n 5 README.md
~~~

`head` 适合快速确认文件格式、表头、配置开头或数据样例，不必读取整个文件。

### 用 `tail` 查看结尾

`tail` 默认显示文件最后 10 行：

~~~bash
tail README.md
~~~

同样可以使用 `-n` 指定行数：

~~~bash
tail -n 5 README.md
~~~

日志通常把最新记录追加到文件末尾，所以 `tail` 很适合查看最近发生的事件。

### 用 `tail -f` 持续观察变化

`tail -f` 会先显示文件末尾，然后继续等待；只要文件追加新内容，新内容就会立即显示：

~~~bash
tail -f /var/log/example.log
~~~

`-f` 表示 follow，即“持续跟随”。`tail -f` 不会自动返回提示符，需要按 `Ctrl-C` 结束观察。

这种方式常用于：

- 观察服务启动日志。
- 复现问题时查看新错误。
- 确认请求是否到达服务。
- 验证程序是否持续产生输出。

`tail -f` 主要跟踪追加到文件末尾的内容，不是用来比较整个文件发生了哪些修改。

### 文件与命令输出使用相同工具

`head`、`tail` 和 `less` 不仅能读取文件，也能通过管道处理命令输出：

~~~bash
ls --help | head -n 5
ls --help | tail -n 5
ls --help | less
~~~

这体现了 Linux 命令组合的重要思路：查看工具只关心输入文本，不必知道文本来自文件还是另一个命令。

## 示例：查看同一个文件的不同部分

先在 `/tmp` 中创建一个练习文件：

~~~bash
printf 'line 1\nline 2\nline 3\nline 4\nline 5\n' > /tmp/file-view-example.txt
~~~

分别查看全部内容、前两行和后两行：

~~~bash
cat /tmp/file-view-example.txt
head -n 2 /tmp/file-view-example.txt
tail -n 2 /tmp/file-view-example.txt
~~~

三个命令读取的是同一个文件，但关注范围不同。选择工具前，先明确自己需要“全部、开头、结尾还是持续变化”。

## 小结（掌握范围）

本课必须掌握：

- 会使用 `cat` 查看较短文本文件的完整内容。
- 知道 `cat -n` 可以显示行号。
- 会使用 `less` 分页阅读，并掌握搜索、翻页和退出操作。
- 会使用 `head -n 行数` 查看文件开头。
- 会使用 `tail -n 行数` 查看文件结尾。
- 会使用 `tail -f` 持续观察追加内容，并用 `Ctrl-C` 退出。
- 能根据文件长度、目标位置和是否持续变化选择合适命令。
- 知道这些查看工具既能读取文件，也能通过管道处理命令输出。

## 课后小实操

### 实操一

创建一个临时文本文件，分别查看全部内容、开头和结尾，并使用 `less` 完成分页阅读。

**操作步骤**

~~~bash
printf 'line 1\nline 2\nline 3\nline 4\nline 5\n' > /tmp/file-view-practice.txt
cat /tmp/file-view-practice.txt
head -n 2 /tmp/file-view-practice.txt
tail -n 2 /tmp/file-view-practice.txt
less /tmp/file-view-practice.txt
~~~

进入 `less` 后尝试使用 `g`、`G` 和 `/line 3`，最后按 `q` 退出。

**运行结果**

~~~text
❯ printf 'line 1\nline 2\nline 3\nline 4\nline 5\n' > /tmp/file-view-practice.txt
❯ cat /tmp/file-view-practice.txt
line 1
line 2
line 3
line 4
line 5
❯ head -n 2 /tmp/file-view-practice.txt
line 1
line 2
❯ tail -n 2 /tmp/file-view-practice.txt
line 4
line 5
❯ less /tmp/file-view-practice.txt

~~~


### 实操二

使用两个终端模拟日志持续写入与实时查看。练习文件位于 `/tmp`，不会修改仓库内容。

**操作步骤**

在终端一中执行：

~~~bash
printf 'service started\n' > /tmp/live-log-practice.log
tail -f /tmp/live-log-practice.log
~~~

保持终端一继续运行，在终端二中执行：

~~~bash
printf 'request accepted\n' >> /tmp/live-log-practice.log
printf 'request finished\n' >> /tmp/live-log-practice.log
~~~

观察终端一是否立即出现两条新记录，然后在终端一按 `Ctrl-C` 结束 `tail -f`。

**运行结果**

~~~text
❯ tail -f /tmp/live-log-practice.log
service started
request accepted
request finished

~~~
