# 提取和转换文本

## 引入

很多文本数据已经有一定结构，例如用逗号分隔的记录、用冒号分隔的配置项，或者日志中的固定关键词。实际工作中，我们经常只需要其中一列、替换某个词，或者把大小写和格式统一。

`cut` 负责提取字段或字符，`tr` 负责逐字符转换，`sed` 负责按行进行简单编辑。它们都可以接收管道输入，因此适合和前面学过的 `grep`、`sort`、`wc` 组合。

## 核心内容

### 先选择合适的工具

| 任务 | 推荐命令 |
| --- | --- |
| 从分隔文本中取出某列 | `cut` |
| 替换、删除或压缩单个字符 | `tr` |
| 按行替换文本或选择行 | `sed` |

本课只处理结构简单的文本，不讨论带复杂引号和嵌套逗号的完整 CSV 格式。

### 用 `cut` 提取字段

`cut` 可以从每行中取出指定字段。基本形式是：

~~~bash
cut -d ',' -f 1 data.csv
~~~

其中：

- `-d ','` 指定字段分隔符是逗号。
- `-f 1` 表示取第 1 个字段。

假设文件内容是：

~~~text
api,120,success
worker,45,success
~~~

执行：

~~~bash
cut -d ',' -f 1 data.csv
~~~

输出：

~~~text
api
worker
~~~

也可以一次提取多个字段：

~~~bash
cut -d ',' -f 1,3 data.csv
~~~

输出：

~~~text
api,success
worker,success
~~~

`cut` 也可以按字符位置提取：

~~~bash
printf 'abcdef\n' | cut -c 1-3
~~~

输出：

~~~text
abc
~~~

注意，`cut -d` 适合处理“每行使用单个字符作为分隔符”的简单格式。多个空格、复杂 CSV 引号或可变结构的文本，需要之后学习更强的工具。

### 用 `tr` 转换字符

`tr` 从标准输入读取文本，并逐字符转换：

~~~bash
printf 'hello\n' | tr '[:lower:]' '[:upper:]'
~~~

输出：

~~~text
HELLO
~~~

`[:lower:]` 表示小写字符集合，`[:upper:]` 表示大写字符集合。

`tr` 也可以把一种字符替换成另一种字符：

~~~bash
printf 'api,worker,database\n' | tr ',' ' '
~~~

输出：

~~~text
api worker database
~~~

`tr` 处理的是字符，不是完整单词。例如，它适合把逗号换成空格，但不适合把字符串 `pending` 整体替换成 `queued`；这种任务更适合使用 `sed`。

### 用 `tr -d` 删除字符

`-d` 表示 delete，可以删除指定字符：

~~~bash
printf '2026-09-19\n' | tr -d '-'
~~~

输出：

~~~text
20260919
~~~

`tr -d` 适合删除换行以外的特定字符，例如冒号、空格或回车符。使用前要确认删除字符不会破坏数据含义。

### 用 `tr -s` 压缩重复字符

`-s` 表示 squeeze，将连续重复的目标字符压缩成一个：

~~~bash
printf 'api    worker\n' | tr -s ' '
~~~

输出：

~~~text
api worker
~~~

这在处理字段之间空格数量不统一的简单文本时很有用。

### 用 `sed` 按行替换文本

`sed` 是 stream editor，即流编辑器。最常见的替换写法是：

~~~bash
sed 's/old/new/' file.txt
~~~

`s/old/new/` 表示把每行中第一个 `old` 替换为 `new`：

~~~bash
printf 'status: pending\nstatus: pending\n' | sed 's/pending/queued/'
~~~

输出：

~~~text
status: queued
status: queued
~~~

如果一行中可能有多处匹配，需要在最后加 `g`：

~~~bash
printf 'pending pending\n' | sed 's/pending/queued/g'
~~~

输出：

~~~text
queued queued
~~~

`sed` 默认只把修改后的结果写到标准输出，不会直接修改源文件。初学时不要使用 `sed -i`，先确认输出正确，再考虑如何安全地写回文件。

### 用 `sed -n` 只显示指定行

`sed -n` 会关闭默认输出，配合 `p` 只打印明确选择的行：

~~~bash
printf 'line 1\nline 2\nline 3\nline 4\n' | sed -n '2,3p'
~~~

输出：

~~~text
line 2
line 3
~~~

`2,3p` 表示打印第 2 行到第 3 行。这个写法适合从小型配置或文本结果中截取指定范围。

### 把工具组合起来

三个命令可以通过管道组成一条处理链：

~~~bash
printf 'api,success\nworker,error\n' | cut -d ',' -f 2 | tr '[:lower:]' '[:upper:]'
~~~

处理过程是：

1. `printf` 产生两行逗号分隔的记录。
2. `cut` 提取第 2 列状态。
3. `tr` 把状态统一转换成大写。

结果是：

~~~text
SUCCESS
ERROR
~~~

每个命令只负责一件事，管道负责把上一步的结果交给下一步。

### 三个容易混淆的地方

1. `cut -d` 的分隔符通常是一个字符，不适合直接解析复杂 CSV。
2. `tr` 逐字符处理，不能直接完成完整单词替换。
3. `sed` 默认输出全部输入行；使用 `sed -n` 时，只有明确打印的行才会输出。

## 示例：提取状态并统一格式

准备一份简单的服务记录：

~~~bash
printf 'api,success\nworker,error\ndatabase,success\n' > /tmp/service-status.txt
~~~

只提取状态字段，并转换成大写：

~~~bash
cut -d ',' -f 2 /tmp/service-status.txt | tr '[:lower:]' '[:upper:]'
~~~

替换错误状态：

~~~bash
sed 's/error/retry/g' /tmp/service-status.txt
~~~

这些命令只把转换结果写到终端，不会修改原文件。

## 小结（掌握范围）

本课必须掌握：

- 会使用 `cut -d 分隔符 -f 字段` 提取简单分隔文本中的字段。
- 会使用 `cut -c` 按字符位置提取内容。
- 会使用 `tr` 转换字符，使用 `tr -d` 删除字符，使用 `tr -s` 压缩重复字符。
- 会使用 `sed 's/旧文本/新文本/'` 进行简单替换。
- 知道 `sed` 默认不会修改源文件。
- 会使用 `sed -n '起始行,结束行p'` 选择指定行。
- 能区分 `cut`、`tr` 和 `sed` 的适用场景。
- 能通过管道组合多个文本处理命令。

## 课后小实操

### 实操一

从逗号分隔的服务记录中提取服务名、状态和延迟字段，并对延迟进行数字排序。

**操作步骤**

~~~bash
printf 'api,120,success\nworker,45,success\napi,300,error\n' > /tmp/text-fields-practice.csv

cut -d ',' -f 1 /tmp/text-fields-practice.csv
cut -d ',' -f 2,3 /tmp/text-fields-practice.csv
cut -d ',' -f 2 /tmp/text-fields-practice.csv | sort -n
~~~

**运行结果**

~~~text
❯ cut -d ',' -f 1 /tmp/text-fields-practice.csv
api
worker
api
❯ cut -d ',' -f 2,3 /tmp/text-fields-practice.csv
120,success
45,success
300,error
❯ cut -d ',' -f 2 /tmp/text-fields-practice.csv | sort -n
45
120
300
~~~

### 实操二

统一文本大小写、替换完整单词，并截取指定行。所有操作只输出结果，不修改练习文件。

**操作步骤**

~~~bash
printf 'status: pending\nstatus: pending\nstatus: done\n' > /tmp/text-transform-practice.txt

tr '[:lower:]' '[:upper:]' < /tmp/text-transform-practice.txt
sed 's/pending/queued/g' /tmp/text-transform-practice.txt
sed -n '1,2p' /tmp/text-transform-practice.txt
~~~

**运行结果**

~~~text
❯ tr '[:lower:]' '[:upper:]' < /tmp/text-transform-practice.txt
STATUS: PENDING
STATUS: PENDING
STATUS: DONE
❯ sed 's/pending/queued/g' /tmp/text-transform-practice.txt
status: queued
status: queued
status: done
❯ sed -n '1,2p' /tmp/text-transform-practice.txt
status: pending
status: pending

~~~
