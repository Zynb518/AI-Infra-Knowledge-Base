# Linux 与操作系统知识地图

> 面向 AI Infra 的 Linux 与操作系统子知识库入口。
>
> 学习目标不是记住命令，而是建立“工作负载 → 内核机制 → 系统指标 → 定位工具 → 工程决策”的完整链路。
>
> **范围边界：本子知识库不讲网络协议、Linux 网络栈、网络隔离或网络排障；这些内容统一归入 网络基础知识地图。

## 一次排障应走完的链路

```text
用户症状
  ↓ 明确错误率、吞吐、平均延迟与尾延迟
工作负载
  ↓ 判断 CPU / 内存 / 存储 I/O / 锁竞争
资源指标
  ↓ 找到饱和、错误或延迟异常的资源
进程与系统调用
  ↓ 使用 pidstat / lsof / strace 缩小范围
内核与硬件
  ↓ 使用 perf / eBPF / NUMA 与设备指标验证
根因与修复
  ↓ 对照实验、回归测试、记录边界条件
```

## 子知识库完成标准

- 能解释进程、线程、虚拟内存、文件描述符和系统调用之间的关系。
- 能解释 page fault、page cache、swap 与 OOM 的发生条件和性能影响。
- 能根据 CPU、内存和存储指标区分不同类型的瓶颈。
- 能用 `strace`、`perf`、`pidstat`、`lsof` 等工具为判断提供证据。
- 能解释 namespace 提供什么视图隔离、cgroups 如何实施资源控制。
- 能分析 CPU affinity、NUMA 和 Host↔Device 数据路径对 GPU/NPU 工作负载的影响。
- 能完成一次从复现、观测、假设到验证和复盘的系统故障分析。
