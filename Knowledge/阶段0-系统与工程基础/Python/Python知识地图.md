# Python 知识地图

> 面向已有一定 Python 基础的学习者，先快速复习环境管理与语言基础，再学习常用数据处理库。
>
> 本轮只学习 Conda 环境管理和 Python 基础语法；NumPy、Pandas 保留为后续章节。基础语法阶段只使用 Python 自带功能和标准库。

## 全景知识目录

```text
Python
├── Conda 环境管理
│   ├── 环境创建与切换
│   └── 包管理与环境复现
├── Python 基础语法
│   ├── 值、变量与容器
│   ├── 条件、循环与推导式
│   ├── 函数与类型标注
│   ├── 模块与类
│   └── 异常、文件与标准库
├── NumPy
│   ├── 数组创建与索引
│   └── 形状、广播与数组计算
└── Pandas
    ├── 数据结构与读取
    └── 数据选择、清洗与汇总
```

## 推荐学习顺序

1. **Conda 环境管理**：能确认正在使用的 Python，并在独立环境中运行代码。
2. **Python 基础语法**：以短课和实操复习编写脚本需要的核心语法。本轮学到这里，完成每课实操并检查结果后再进入下一课。
3. **NumPy**：需要处理数组数据时再开始。
4. **Pandas**：具备数组基础后，再学习表格数据处理。

主题目录和具体笔记随学习进度创建，不预先创建空目录或空笔记。

## 完成标准

### 本轮完成标准

- 能创建、切换和检查 Conda 环境，确认脚本使用的 Python 解释器。
- 能独立编写使用容器、控制流、函数、模块和基础类型标注的小脚本。
- 能读取文件、处理常见异常，并使用标准库完成简单数据整理。
- 能提交每课实操的代码与实际运行结果，并解释关键输出。

### 后续章节完成标准

- 能用 NumPy 创建和操作数组，解释形状变化与广播结果。
- 能用 Pandas 读取、筛选、清洗和汇总表格数据，并检查处理结果。
