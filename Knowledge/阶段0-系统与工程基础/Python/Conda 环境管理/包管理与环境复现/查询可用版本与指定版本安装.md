# 查询可用版本与指定版本安装

## 引入

前两课会安装、更新和移除包，但如果任务要求某个指定版本，还需要先知道软件源提供哪些版本，再让 Conda 判断该版本能否放进现有环境。

本课继续使用 `py-basics`。先区分“已安装版本”和“可搜索到的版本”，再练习指定版本安装。不会因为搜索结果里有某个版本，就直接认定它与环境兼容。[Conda 搜索命令文档](https://docs.conda.io/projects/conda/en/stable/commands/search.html)

## 核心内容

### 已安装版本与可用版本是两种查询

```bash
conda list -n py-basics setuptools
conda search setuptools
```

`conda list -n py-basics` 只看 `py-basics` 中已经安装的包；`conda search` 查询当前配置的软件源，为本机平台列出能找到的版本和构建。搜索结果可能有多行属于同一个版本，因为一个版本可以有不同构建。这里说的“可用版本”，指当前软件源和平台能查到的记录，不是这个软件发布过的所有历史版本。[Conda 包搜索说明](https://docs.conda.io/projects/conda/en/stable/user-guide/tasks/manage-pkgs.html#searching-for-packages)

如果只想查看一个版本的记录，可以把包名和版本写在一起：

```bash
conda search 'setuptools=83.0.0'
```

单引号让 Shell 原样传递这个查询条件。筛选后的结果仍可能有多个构建；是否能安装到 `py-basics`，还要由 Conda 根据 Python 和其他已安装包求解。

### 指定版本并先预览

例如，要明确指定当前练习环境已有的 `setuptools 83.0.0`，先预览：

```bash
conda install -n py-basics 'setuptools=83.0.0' --dry-run
```

`包名=版本` 是 Conda 的版本约束写法；`-n py-basics` 指定目标环境，`--dry-run` 只显示计划。这个例子中的版本已经安装，因此可能显示没有需要改动的包。选择其他可搜索到的版本时，重点看计划中的目标路径、目标版本，以及是否连带改变 Python 或其他包。若求解失败，说明这个版本在当前环境和软件源配置下不能直接安装，换一个版本再预览。[Conda 指定版本安装说明](https://docs.conda.io/projects/conda/en/stable/user-guide/tasks/manage-pkgs.html#installing-packages)

确认计划合适后，去掉 `--dry-run` 才实际安装：

```bash
conda install -n py-basics 'setuptools=83.0.0'
conda list -n py-basics setuptools
```

安装命令会再次显示计划并等待确认。安装结束后查询目标环境，检查包名和版本，不能只凭“事务完成”判断装上的版本。若版本原本就已安装，实际命令通常不会重新安装它。

## 示例

本机 `py-basics` 当前有 `setuptools 83.0.0`。`conda list -n py-basics setuptools` 只能证明这个版本已安装；`conda search setuptools` 则用于比较软件源提供的其他版本。对 `'setuptools=83.0.0'` 进行安装预览时，即使没有需要改动的包，也能验证指定版本的写法和目标环境。课后实操会换成尚未安装的 `wheel`，完成真正的指定版本安装。

## 小结（掌握范围）

- 能区分环境中已安装的版本与软件源中可搜索到的版本。
- 会用 `conda search` 查看当前软件源和平台的版本记录，并筛选指定版本。
- 会用 `包名=版本` 指定安装版本，先预览变更，再确认安装。
- 会在安装后查询目标环境，核对实际得到的版本。

## 课后小实操

### 实操一

在 `py-basics` 中安装一个你自行选定版本的 `wheel`，为后续环境复现练习留下一个明确的版本记录。课堂示例使用的是已安装的 `setuptools`；本题要从搜索结果中选择尚未安装的包及其版本。

**操作步骤**

先确认 `py-basics` 中没有 `wheel`，再查询当前软件源中 `wheel` 的版本记录，挑选一个候选版本。对该版本预览安装计划，确认目标是 `py-basics`，并查看是否连带改变了不希望变化的包；计划合适时再执行指定版本安装。完成后查询 `py-basics` 中实际安装的 `wheel` 版本。若所选版本无法求解，保留报错，改选搜索结果中的另一个版本重新预览。

运行结果只需贴出你选择的版本及其搜索记录、预览计划的目标路径与关键变更行、安装后的版本记录；无需粘贴全部搜索结果或下载日志。
