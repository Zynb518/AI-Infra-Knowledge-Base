# 包管理与环境复现

[返回 Conda 环境管理](<../Conda 环境管理.md>)

本主题先学习查询和安装指定环境中的软件包，再学习把环境配置保存下来并用于复现。练习使用已有的 `py-basics` 环境。

## 课程导航

1. [查看与安装 Conda 包](<./查看与安装 Conda 包.md>)

   学习用 `conda list -n` 查询指定环境的包，用 `conda install -n ... --dry-run` 预览计划，再安装并核对结果。

2. [更新与移除 Conda 包](<./更新与移除 Conda 包.md>)

   学习用 `conda update` 和 `conda remove` 查看变更计划、移除指定包，并用 `conda install` 恢复。

3. [查询可用版本与指定版本安装](<./查询可用版本与指定版本安装.md>)

   学习用 `conda search` 查看可用版本，以 `包名=版本` 指定版本，预览安装并用 `conda list` 核对。

4. [导出并复现 Conda 环境](<./导出并复现 Conda 环境.md>)

   学习用 `conda export --from-history` 生成环境 YAML，用 `conda env create -n` 建立新环境，并用 `conda list` 核对 Python、`setuptools` 和 `wheel`。

完成当前课程的实操并提交实际运行结果后，再继续后续课程。
