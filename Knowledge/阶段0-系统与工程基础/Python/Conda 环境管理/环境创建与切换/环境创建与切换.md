# 环境创建与切换

[返回 Conda 环境管理](<../Conda 环境管理.md>)

本主题先在本机安装 Miniconda，再学习创建独立环境、激活与退出环境、查看已有环境，以及确认当前命令使用的 Python 解释器。

## 课程导航

1. [在 Linux 上安装 Miniconda](<./在 Linux 上安装 Miniconda.md>)

   学习选择 Linux 安装程序、用 `sha256sum` 核对摘要、执行 `conda init zsh`，并用 `conda --version` 验证安装。

2. [创建与切换 Conda 环境](<./创建与切换 Conda 环境.md>)

   学习使用 `conda create`、`conda info --envs`、`conda activate` 和 `conda deactivate`，并用 `command -v python` 核对解释器路径。

按顺序完成每课实操并提交实际运行结果，再继续下一课。
