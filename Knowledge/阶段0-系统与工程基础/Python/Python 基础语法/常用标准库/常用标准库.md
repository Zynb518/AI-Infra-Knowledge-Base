# 常用标准库

[返回 Python 基础语法](<../Python 基础语法.md>)

本主题按实际用途复习五个 Python 标准库模块。课程笔记随学习进度逐一创建。

## 学习范围

1. `pathlib`：拼接路径、检查文件、查找文件。
2. `os`：工作目录、环境变量、进程信息。
3. `json`：Python 数据与 JSON 的转换，以及 JSON 文件读写。
4. `datetime`：日期时间、格式转换、时间差。
5. `re`：用正则表达式查找、提取、替换文本。

## 课程导航

1. [pathlib 路径操作](<./pathlib 路径操作.md>)

   学习用 `Path`、`/`、`cwd()` 和 `home()` 构造路径，查看 `name`、`stem`、`suffix`、`parent`，用 `exists()`、`is_file()`、`glob()`、`rglob()` 检查和查找，并用 `mkdir()`、`read_text()`、`write_text()`、`rename()`、`unlink()` 管理文件。

2. [os 与运行环境](<./os 与运行环境.md>)

   学习用 `getcwd()`、`chdir()` 处理工作目录，用 `environ`、`getenv()` 读写环境变量，用 `getpid()`、`cpu_count()` 查看进程和系统信息，并用 `listdir()`、`walk()` 遍历目录。
