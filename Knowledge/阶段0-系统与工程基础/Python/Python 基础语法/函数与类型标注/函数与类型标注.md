# 函数与类型标注

[返回 Python 基础语法](<../Python 基础语法.md>)

本主题复习如何把重复的处理步骤组织成函数，并用类型标注表达参数与返回值的预期类型。

## 课程导航

1. [函数定义、参数与返回值](<./函数定义、参数与返回值.md>)

   学习用 `def` 定义和调用函数，使用位置参数、关键字参数和默认参数，通过 `return` 返回结果，并理解函数局部作用域。

2. [参数、返回值与容器类型标注](<./参数、返回值与容器类型标注.md>)

   学习用 `:` 和 `->` 标注参数、变量与返回值，用 `list[str]`、`dict[str, int]` 和 `str | None` 描述常见类型，并了解标注不会自动检查运行时数据。
