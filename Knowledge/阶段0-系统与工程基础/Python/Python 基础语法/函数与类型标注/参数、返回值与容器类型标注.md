# 参数、返回值与容器类型标注

## 引入

Python 函数可以给参数和返回值添加类型标注，让读代码的人和开发工具更容易理解数据预期。本课学习常用写法，也区分类型标注与运行时类型检查。

## 核心内容

### 标注参数和返回值

参数名后用冒号标注类型，函数定义后用 `->` 标注返回值类型：

```python
def repeat(text: str, count: int) -> str:
    return text * count

message = repeat("Hi! ", 2)
print(message)
```

`text: str` 表示参数预期是字符串，`count: int` 表示预期是整数，`-> str` 表示返回值预期是字符串。没有有意义的返回值时可标注 `-> None`。

### 标注变量和常见容器

变量也可以添加类型标注。容器类型用方括号说明元素、键和值的类型：

```python
name: str = "小林"
scores: list[int] = [90, 85]
score_by_subject: dict[str, int] = {"语文": 90, "数学": 85}
tags: set[str] = {"Python", "基础"}
coordinate: tuple[int, int] = (3, 5)
```

例如，`list[int]` 表示预期保存整数的列表，`dict[str, int]` 表示预期使用字符串键和整数值的字典。Python 3.14 可以直接使用这些内置容器类型写法。

`list[int]` 不会把列表变成只能装整数的特殊容器。Python 列表运行时仍能保存不同类型的对象；但若把混合内容标注为 `list[int]`，就违背了标注表达的预期，类型检查工具可能会报告问题。对有意混合多种类型的列表，可以使用 `list[object]`，或用联合类型准确列出允许的元素类型：

```python
mixed: list[int | str | float | list[int] | tuple[int, ...]] = [
    1, "hello", 3.14, [2], (3,)
]
print(mixed)
```

这里的 `|` 表示每个元素可以是所列类型中的任意一种；`tuple[int, ...]` 表示由零个或多个整数组成的元组。

### 表示多种可能类型

使用 `|` 表示一个值可能属于几种类型中的一种。常见情况是返回值可能是某个类型，也可能是 `None`：

```python
def find_name(user_id: int, names: dict[int, str]) -> str | None:
    return names.get(user_id)
```

这里的返回值预期是字符串或 `None`；因为字典中可能没有传入的 `user_id`。

### 类型标注不会自动检查或转换

类型标注表达的是预期，不会自动把传入值转换成标注类型，也不会单独阻止不符合标注的数据运行。IDE 或类型检查工具可以读取标注并报告不一致；实际运行仍由函数代码和操作决定。

例如，`count: int` 不会把字符串自动转成整数；如果函数执行了不支持该值类型的运算，仍会按实际运算规则报错。

## 示例

下面标注一个汇总函数的输入列表、返回字典和每个字段的类型：

```python
def summarize(scores: list[int]) -> dict[str, int]:
    total = 0
    for score in scores:
        total += score

    return {"count": len(scores), "total": total}

result = summarize([90, 85, 100])
print(result)
```

标注帮助读者看出函数接收整数列表，并返回包含整数统计值的字典；真正的计算仍由函数体完成。

## 小结（掌握范围）

- 能用 `参数名: 类型` 和 `-> 返回类型` 标注函数。
- 能用 `list[int]`、`dict[str, int]`、`set[str]` 和 `tuple[int, int]` 表达常见容器内容类型。
- 能用 `类型一 | 类型二` 表示多种可能类型，例如 `str | None`。
- 知道类型标注用于表达预期、支持阅读和工具分析，不会自动转换或校验运行时数据。
