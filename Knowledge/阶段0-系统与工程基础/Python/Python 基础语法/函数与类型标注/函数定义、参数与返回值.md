# 函数定义、参数与返回值

## 引入

当一段处理逻辑需要多次使用，或需要把大任务拆成更小的步骤时，可以把逻辑写进函数。函数让代码有名字、能接收输入，并可以把处理结果交还给调用者。

## 核心内容

### 定义和调用函数

使用 `def` 定义函数，函数体需要缩进；写出函数名并加上括号，就会调用函数：

```python
def greet():
    print("你好")

greet()
```

定义函数只是在说明要执行的步骤；调用函数后，函数体才会运行。

### 参数和实参

定义时括号中的名称叫参数，调用时传入的值叫实参。调用时按位置传值是位置参数；写出参数名传值是关键字参数：

```python
def describe(name, role):
    print(f"{name} 的角色是 {role}")

describe("小林", "维护者")
describe(role="维护者", name="小林")
```

位置参数按定义顺序对应参数；关键字参数按名称对应，所以可以调整传入顺序。

### 默认参数

定义参数时可以设置默认值。调用时省略该参数，就会使用默认值：

```python
def greet(name, greeting="你好"):
    print(f"{greeting}，{name}")

greet("小林")
greet("小林", "早上好")
```

有默认值的参数要放在没有默认值的参数之后。

### 用 `return` 返回结果

`print()` 负责显示内容；`return` 把值交还给调用者，供后续计算或保存：

```python
def add(left, right):
    return left + right

total = add(2, 3)
print(total)
```

如果函数没有执行 `return`，它会返回 `None`。如果需要在函数外继续使用计算结果，应当返回结果，而不只是打印它。

### 函数的局部作用域

函数参数和函数体内赋值的名称属于该次函数调用的局部作用域。它们不能像 `if` 代码块中的变量那样，在函数外直接使用；需要把值交给外部时，用 `return` 返回：

```python
def make_label(item):
    label = f"项目：{item}"
    return label

result = make_label("Python")
print(result)
```

这里 `item` 和 `label` 是函数内部使用的名称，外部通过 `result` 接收函数的返回值。

## 示例

下面的函数计算商品总价，数量默认是 `1`；调用时使用关键字参数指定数量：

```python
def line_total(unit_price, quantity=1):
    subtotal = unit_price * quantity
    return subtotal

amount = line_total(2.5, quantity=4)
print(f"总价：{amount}")
```

`line_total()` 返回 `10.0`，调用者把结果保存到 `amount` 后再显示出来。参数的类型标注将在本主题后续课程介绍。

## 小结（掌握范围）

- 能用 `def` 定义函数并通过函数名调用。
- 能区分参数与实参，并使用位置参数、关键字参数和默认参数。
- 能区分 `print()` 的显示作用和 `return` 的返回作用。
- 知道函数参数和函数体内名称属于函数局部作用域，需要时用 `return` 把结果传出。
