# 类与对象

## 引入

当数据和处理这些数据的函数经常一起使用时，可以把它们组织在一个类中。类描述对象有哪些数据和行为；根据类创建出的具体对象称为实例。

## 核心内容

### 定义类和创建实例

使用 `class` 定义类，再像调用函数一样调用类，创建该类的实例：

```python
class Book:
    pass

book = Book()
```

这里 `Book` 是类，`book` 是根据它创建的实例。`pass` 表示此处暂时没有要执行的语句。

### 用 `__init__` 初始化实例属性

定义 `__init__` 方法，可以在创建实例时接收数据，并将数据保存到实例上：

```python
class Book:
    def __init__(self, title, pages):
        self.title = title
        self.pages = pages

book = Book("Python 基础", 320)
print(book.title)
```

创建 `Book` 实例时，传入的标题和页数会交给 `__init__`。`self.title` 和 `self.pages` 是实例属性，分别保存到当前对象中；`title` 和 `pages` 是初始化时收到的参数。

### 用 `self` 表示当前实例

实例方法的第一个参数通常命名为 `self`，它指向当前实例。调用 `book.summary()` 时，Python 会自动把 `book` 作为第一个参数传给方法；`self` 是约定俗成的名字，不是 Python 关键字。

```python
class Book:
    def __init__(self, title, pages):
        self.title = title
        self.pages = pages

    def summary(self):
        return f"《{self.title}》共 {self.pages} 页"

book = Book("Python 基础", 320)
print(book.summary())
```

`summary` 是定义在类里的函数，通常通过实例调用，称为实例方法。它可以通过 `self` 读取或修改当前实例的属性。

### 每个实例保存各自的数据

同一个类可以创建多个实例。通过 `self` 保存的实例属性属于各自对象：

```python
first = Book("Python 基础", 320)
second = Book("Linux 入门", 240)

print(first.title)
print(second.title)
```

修改一个实例的 `title` 不会自动修改另一个实例的 `title`。

## 示例

下面定义一个待办事项类，每个实例保存自己的标题和完成状态，并提供修改状态的方法：

```python
class Task:
    def __init__(self, title):
        self.title = title
        self.done = False

    def mark_done(self):
        self.done = True

task = Task("复习 Python 类")
task.mark_done()
print(task.title)
print(task.done)
```

`mark_done()` 修改的是调用它的那个实例的 `done` 属性。

## 小结（掌握范围）

- 能用 `class` 定义类，并通过调用类创建实例。
- 能用 `__init__` 接收创建实例时的数据。
- 能通过 `self.属性名` 保存和访问实例属性。
- 能定义实例方法，并通过实例调用方法、读取或修改当前实例的数据。
