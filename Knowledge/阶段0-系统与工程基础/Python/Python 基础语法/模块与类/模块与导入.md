# 模块与导入

## 引入

程序变大后，把相关函数和变量放在不同的 `.py` 文件中，可以让代码更容易查找和复用。Python 把这样的文件作为模块，并通过导入语句让其他文件使用它。

## 核心内容

### `.py` 文件就是模块

例如，文件 `greeting.py` 可以定义一个函数。导入时通常写文件名去掉 `.py` 后缀的模块名：

```python
# greeting.py
def greet(name):
    return f"你好，{name}"
```

### 导入模块或其中的名称

`import 模块名` 导入模块，通过 `模块名.名称` 使用其内容；`from 模块名 import 名称` 则直接导入指定名称。两种写法都可以用 `as` 设置别名：

```python
import math
print(math.sqrt(9))

from math import sqrt as square_root
print(square_root(16))
```

使用 `import math` 时，`sqrt` 通过 `math.sqrt` 访问；直接导入后，可以使用别名 `square_root`。

### 导入时会执行模块顶层语句

第一次导入模块时，模块中的函数定义、变量赋值和其他顶层语句会执行。因此，模块顶层通常放函数、类和常量定义，避免导入时意外运行一整段程序。

`__name__` 是模块的特殊变量：直接运行文件时，它的值是 `"__main__"`；作为模块导入时，它的值是模块名。可以用这个条件把仅供直接运行的代码放在保护块中：

```python
if __name__ == "__main__":
    print(greet("Python"))
```

直接运行 `greeting.py` 时会执行保护块；其他文件导入 `greeting` 时，保护块不会执行。

它的主要用途是让同一个文件既能被其他模块导入并复用，又能在直接运行时执行演示、测试或程序入口代码。这样，导入函数和类时不会意外触发这些入口操作。注意，保护块之外的模块顶层语句仍会在导入时执行。

## 示例

下面将函数放在 `greeting.py` 中，再由 `main.py` 导入并调用。

`greeting.py`：

```python
def greet(name):
    return f"你好，{name}"

if __name__ == "__main__":
    print(greet("Python"))
```

`main.py`：

```python
import greeting as greet_module

print(greet_module.greet("小林"))
```

在这两个文件所在目录运行 `main.py` 时，输出“你好，小林”。导入 `greeting` 会执行模块顶层的函数定义，但不会执行只用于直接运行的保护块。

## 小结（掌握范围）

- 知道 `.py` 文件可以作为模块，并能用模块名访问其中的名称。
- 能使用 `import`、`from ... import` 和 `as` 导入模块内容或设置别名。
- 知道导入会执行模块顶层语句。
- 能用 `if __name__ == "__main__"` 将直接运行的代码与导入时的行为区分开。
