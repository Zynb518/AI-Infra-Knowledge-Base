# 模块与类

[返回 Python 基础语法](<../Python 基础语法.md>)

本主题复习如何拆分和导入 Python 模块，以及如何用类组织数据和相关操作。

## 课程导航

1. [模块与导入](<./模块与导入.md>)

   学习把 `.py` 文件作为模块，通过 `import`、`from ... import` 和别名导入内容，并用 `if __name__ == "__main__"` 区分直接运行与被导入。

2. [类与对象](<./类与对象.md>)

   学习用 `class` 定义类，用 `__init__` 和 `self` 初始化实例属性，并通过实例调用方法。

3. [继承与方法重写](<./继承与方法重写.md>)

   学习用 `class 子类(父类)` 继承属性和方法，重写父类方法，并用 `super().__init__()` 和 `super().方法()` 复用父类实现。

本主题暂不设置课后实操；按课程导航顺序学习，收到你的明确要求后再添加。
