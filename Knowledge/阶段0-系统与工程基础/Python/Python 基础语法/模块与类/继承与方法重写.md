# 继承与方法重写

## 引入

当一种对象是另一种对象的特殊类型，并且需要沿用它已有的数据和行为时，可以用继承表达这种关系。子类会复用父类的属性和方法，也可以增加自己的内容或重写已有方法。

## 核心内容

### 定义子类

在类名后面的括号中写出父类名，即可定义子类：

```python
class Document:
    def __init__(self, title):
        self.title = title

    def describe(self):
        return f"文档：{self.title}"

class Report(Document):
    pass
```

`Report` 继承了 `Document`，因此它的实例可以使用父类的 `title` 属性和 `describe()` 方法。若子类没有定义自己的 `__init__`，会使用继承来的初始化方法。

### 重写父类方法

在上例定义了 `Document` 之后，子类定义与父类同名的方法，就会为子类实例提供自己的实现：

```python
class Report(Document):
    def describe(self):
        return f"报告：{self.title}"
```

调用 `Report` 实例的 `describe()` 时会使用子类版本；其他 `Document` 实例仍使用父类版本。

### 用 `super()` 扩展父类行为

在上例类定义的基础上，若子类要保留父类完成的工作，再追加自己的内容，可以使用 `super()` 调用继承关系中父类的实现，而不必重复编写：

```python
class Report(Document):
    def __init__(self, title, pages):
        super().__init__(title)
        self.pages = pages

    def describe(self):
        base_description = super().describe()
        return f"{base_description}，共 {self.pages} 页"
```

`super().__init__(title)` 先初始化父类负责的 `title`，子类再保存自己的 `pages`。`super().describe()` 取得父类描述，子类在此基础上补充页数。

继承适合表达“子类是一种父类”的关系，例如报告是一种文档；如果两个类只是碰巧有相同代码，不一定需要用继承连接它们。

## 示例

下面创建报告对象，并调用重写后的方法：

```python
class Document:
    def __init__(self, title):
        self.title = title

    def describe(self):
        return f"文档：{self.title}"

class Report(Document):
    def __init__(self, title, pages):
        super().__init__(title)
        self.pages = pages

    def describe(self):
        description = super().describe()
        return f"{description}，共 {self.pages} 页"

report = Report("Python 学习记录", 12)
print(report.describe())
```

输出会同时包含父类保存的标题和子类保存的页数，说明子类既能复用父类逻辑，也能扩展自己的行为。

## 小结（掌握范围）

- 能用 `class 子类(父类)` 定义继承关系。
- 知道子类可以沿用父类属性和方法，也可以定义自己的 `__init__`。
- 能通过定义同名方法重写父类行为。
- 能用 `super().__init__()` 初始化父类负责的数据，用 `super().方法()` 扩展父类方法。
