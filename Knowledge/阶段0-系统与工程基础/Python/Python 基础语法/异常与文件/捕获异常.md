# 捕获异常

## 引入

脚本处理外部数据时，不能保证每个值都符合预期。例如，文本可能无法转成整数，字典可能缺少需要的键。Python 会用异常报告这类错误；对于能够预料和处理的情况，可以捕获异常，让程序继续完成后续工作。

## 核心内容

### 认识常见异常

异常类型告诉我们错误发生在哪里、属于哪一类：

| 异常类型 | 常见情况 |
| --- | --- |
| `ValueError` | 值的内容不符合要求，例如 `int("12a")` |
| `TypeError` | 操作不支持当前类型组合，例如 `1 + "2"` |
| `KeyError` | 用 `data["name"]` 读取不存在的字典键 |
| `FileNotFoundError` | 读取一个不存在的文件 |

这些异常是 Python 内置的，不需要先导入模块。

### 用 `try` 和 `except` 处理预期错误

把可能出错的语句放进 `try`，用 `except` 指定要处理的异常类型：

```python
raw = "12a"

try:
    count = int(raw)
    print(f"数量：{count}")
except ValueError:
    print("数量不是有效整数")

print("继续处理后续内容")
```

这里 `int(raw)` 会产生 `ValueError`。Python 跳过本次 `try` 中剩余的语句，执行匹配的 `except`，然后继续执行整个 `try` 语句之后的代码。如果把 `raw` 改成 `"12"`，转换成功，`except` 就不会执行。

### 获取错误信息，分别处理不同异常

`except ValueError as error` 会把当前异常交给名称 `error`，便于查看错误信息。一个 `try` 后面也可以写多个 `except`，分别处理不同异常；发生异常时只会进入第一个匹配的处理分支：

```python
record = {"count": "unknown"}

try:
    count = int(record["count"])
except KeyError:
    print("缺少 count 字段")
except ValueError as error:
    print(f"count 无法转成整数：{error}")
except Exception as error:
    print(f"未预料的错误：{type(error).__name__}: {error}")
    raise
```

优先捕获自己知道如何处理的具体异常类型，避免把其他代码错误也当成同一情况处理。

### 为未知错误设置兜底分支

上例最后的 `except Exception` 用来接住 `try` 中未被前两个分支处理的大多数普通异常。它要放在具体异常之后，否则 `KeyError`、`ValueError` 也会先被兜底分支接走。这里的 `raise` 会重新抛出当前异常，避免只打印一条消息就误以为处理成功；只有明确知道如何恢复时，才在兜底分支继续执行。

这个兜底范围是 `try` 中的代码及其调用的函数。它不处理其他 `except` 分支自身抛出的异常，也不捕获表示中断或退出的 `KeyboardInterrupt`、`SystemExit`。

## 示例

下面逐条处理记录。某一条数据不合格时，给出提示并继续处理下一条：

```python
records = [
    {"name": "小林", "count": "3"},
    {"name": "小王", "count": "unknown"},
    {"name": "小周"},
]

for record in records:
    try:
        count = int(record["count"])
        print(f"{record['name']}：{count}")
    except KeyError:
        print(f"{record['name']}：缺少 count")
    except ValueError:
        print(f"{record['name']}：count 不是整数")
```

第一条记录会输出整数 `3`；第二条触发 `ValueError`；第三条触发 `KeyError`。前一条记录的错误不会阻止循环处理后面的记录。

## 小结（掌握范围）

- 能识别 `ValueError`、`TypeError`、`KeyError` 和 `FileNotFoundError` 等常见异常。
- 能用 `try`、`except` 捕获并处理预期异常。
- 能用 `as` 查看异常信息，并用多个 `except` 区分不同错误。
- 能把 `except Exception` 放在具体处理之后，并用 `raise` 保留无法恢复的未知错误。
- 能解释异常发生时 `try` 中剩余语句为何被跳过，以及处理后程序从哪里继续。
