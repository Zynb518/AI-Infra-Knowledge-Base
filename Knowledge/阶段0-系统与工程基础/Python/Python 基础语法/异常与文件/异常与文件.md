# 异常与文件

[返回 Python 基础语法](<../Python 基础语法.md>)

本主题先学习处理运行时可能发生的错误，再学习用 `with` 管理操作的进入与退出，最后读取和写入文本文件。

## 课程导航

1. [捕获异常](<./捕获异常.md>)

   学习用 `try`、`except` 和 `as` 捕获预期错误，认识 `ValueError`、`TypeError`、`KeyError` 与 `FileNotFoundError`，并用最后的 `except Exception` 和 `raise` 兜底未知错误。

2. [异常流程与抛出](<./异常流程与抛出.md>)

   学习在 `try` 后使用 `else` 处理成功结果、用 `finally` 执行收尾操作、用 `raise` 主动抛出错误，并理解异常如何从函数传到调用处。

3. [with 语句与上下文管理器](<./with 语句与上下文管理器.md>)

   学习 `with ... as ...` 如何调用 `__enter__()` 和 `__exit__()`，并用 `TemporaryDirectory`、`Lock` 理解自动清理与释放。

4. [文本文件读写](<./文本文件读写.md>)

   学习用 `with open()` 和 UTF-8 编码读写文本，区分 `r`、`w`、`a` 模式，使用 `read()` 与逐行遍历，并处理 `FileNotFoundError`。

本主题暂不设置课后实操；按课程导航顺序学习，收到你的明确要求后再添加。
