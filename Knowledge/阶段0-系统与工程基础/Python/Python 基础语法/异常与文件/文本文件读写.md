# 文本文件读写

## 引入

脚本中的变量只在运行期间存在；把数据写入文件，下一次运行时仍能读取。Python 内置的 `open()` 可以读写文本文件；前一课介绍的 [with 语句](<./with 语句与上下文管理器.md>) 会在代码块结束后关闭文件。

## 核心内容

### 用 `with open()` 打开文件

`open(文件名, 模式, encoding="utf-8")` 返回文件对象。读取一个已有文本文件可以这样写：

```python
with open("notes.txt", "r", encoding="utf-8") as file:
    content = file.read()

print(content)
```

`with` 代码块结束时会关闭文件，即使块内发生异常也一样。这里的 `notes.txt` 是相对路径，会按运行脚本时的当前工作目录查找。文本中可能包含中文时，明确写出 `encoding="utf-8"` 有助于保持读写一致。

### 区分读取、覆盖写入和追加写入

| 模式  | 用途      | 文件已存在时         |
| --- | ------- | -------------- |
| `r` | 读取文本    | 保留原内容；文件不存在会报错 |
| `w` | 写入文本    | 打开时清空原内容       |
| `a` | 在末尾追加文本 | 保留原内容，新内容写到末尾  |

`w` 和 `a` 在文件不存在时会创建文件。`write()` 只写入给定字符串；需要换行时，应在字符串中写 `\n`：

```python
with open("python_io_demo.txt", "w", encoding="utf-8") as file:
    file.write("第一行\n")

with open("python_io_demo.txt", "a", encoding="utf-8") as file:
    file.write("第二行\n")
```

### 整篇读取与逐行读取

`read()` 把文件全部读入一个字符串，适合较小的文本。需要逐行处理时，可以直接遍历文件对象：

```python
with open("python_io_demo.txt", "r", encoding="utf-8") as file:
    for line in file:
        print(line.rstrip("\n"))
```

每轮 `line` 是一行文本，通常包含行末的换行符。`rstrip("\n")` 在输出前去掉它，避免 `print()` 再添加一个换行造成空行。

### 处理文件不存在

读取不存在的文件会产生 `FileNotFoundError`。如果缺少文件是可以预料的情况，可捕获并给出提示：

```python
try:
    with open("notes.txt", "r", encoding="utf-8") as file:
        print(file.read())
except FileNotFoundError:
    print("没有找到 notes.txt")
```

## 示例

下面完整演示创建文本、追加一行，再逐行读取。代码会在当前工作目录创建或覆盖 `python_io_demo.txt`：

```python
filename = "python_io_demo.txt"

with open(filename, "w", encoding="utf-8") as file:
    file.write("复习异常\n")
    file.write("学习文件读写\n")

with open(filename, "a", encoding="utf-8") as file:
    file.write("继续学习标准库\n")

with open(filename, "r", encoding="utf-8") as file:
    for line in file:
        print(line.rstrip("\n"))
```

运行后会依次看到三行文字。再次运行时，开头的 `w` 会清空上一次的内容，再重新写入这三行。

## 小结（掌握范围）

- 能用 `with open()` 打开文本文件，并明确指定 UTF-8 编码。
- 能区分 `r`、`w`、`a` 模式，知道 `w` 会清空已有内容。
- 能用 `read()` 读取整个文件，用 `for line in file` 逐行处理。
- 能用 `write()` 写入文本和换行符，并处理读取时的 `FileNotFoundError`。
