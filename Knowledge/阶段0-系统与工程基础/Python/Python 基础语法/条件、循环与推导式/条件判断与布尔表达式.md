# 条件判断与布尔表达式

## 引入

脚本经常需要根据数据选择不同处理方式，例如根据分数给出等级，或根据磁盘占用率发出提醒。Python 使用布尔表达式判断条件，再用 `if`、`elif` 和 `else` 选择要执行的代码块。

## 核心内容

### 比较运算符产生布尔值

比较表达式的结果是 `True` 或 `False`：

| 运算符 | 含义 |
| --- | --- |
| `==`、`!=` | 等于、不等于 |
| `>`、`<` | 大于、小于 |
| `>=`、`<=` | 大于等于、小于等于 |

`=` 用于赋值，`==` 用于比较两个值是否相等。

### 用 `if`、`elif` 和 `else` 分支

```python
score = 84

if score >= 90:
    level = "优秀"
elif score >= 60:
    level = "合格"
else:
    level = "需要复习"

print(level)
```

Python 根据顺序检查条件，执行第一个成立的分支；如果前面的条件都不成立，就执行 `else`。`else` 可以省略。条件行末尾需要冒号，分支中的语句需要缩进，通常使用四个空格。

### 缩进不等于块级作用域

缩进标明语句属于哪个分支，但 `if`、`elif` 和 `else` 不会像 C++ 的花括号那样创建独立的变量作用域。在模块顶层，分支中赋值的变量在分支执行后仍可使用：

```python
if True:
    message = "分支已执行"

print(message)
```

在函数中，局部作用域由函数体形成，而不是由 `if` 分支形成。若变量只在某个条件分支中赋值，分支未执行时再读取它会因尚未赋值而报错。

### 用逻辑运算符组合条件

- `and`：两边条件都成立时，结果才成立。
- `or`：至少一边条件成立时，结果就成立。
- `not`：把真假结果反转。

```python
is_member = True
total = 68

if is_member and total >= 50:
    print("符合会员优惠条件")
```

### 常见值的真值判断

条件位置不一定要写比较表达式。Python 会把值判断为真或假：`False`、`None`、数字 `0`、空字符串和空容器会判断为假；其他常见非空值会判断为真。

```pythonj
tasks = []

if tasks:
    print("有待办任务")
else:
    print("没有待办任务")
```

直接判断容器可以简化“是否为空”的检查。

## 示例

下面根据磁盘占用率和环境类型生成状态：占用率达到 `95` 时标记为严重；否则，生产环境占用率达到 `85` 时标记为预警；其他情况标记为正常。

```python
disk_percent = 88
is_production = True

if disk_percent >= 95:
    status = "严重"
elif is_production and disk_percent >= 85:
    status = "预警"
else:
    status = "正常"

print(f"磁盘占用率 {disk_percent}%，状态：{status}")
```

当输入为 `88` 且是生产环境时，第二个分支成立，输出“预警”。

## 小结（掌握范围）

- 能使用比较运算符生成 `True` 或 `False`。
- 能用 `if`、`elif`、`else` 按条件选择分支，并正确缩进代码块。
- 能用 `and`、`or`、`not` 组合或反转条件。
- 能理解常见空值、零和空容器在条件中的真假判断。
