# 列表、字典与集合推导式

## 引入

循环可以逐项处理数据。推导式则把“遍历数据并生成新容器”的常见写法压缩成一行，适合简单的转换、筛选和去重。

## 核心内容

### 列表推导式

基本形式是 `[表达式 for 元素 in 可迭代对象]`。表达式为每个元素生成一个结果：

```python
numbers = [1, 2, 3, 4]
squares = [number ** 2 for number in numbers]
print(squares)
```

在末尾添加 `if 条件` 可以只保留满足条件的元素：

```python
numbers = [1, 2, 3, 4]
even_numbers = [number for number in numbers if number % 2 == 0]
print(even_numbers)
```

### 字典推导式

字典推导式用 `{键表达式: 值表达式 for 元素 in 可迭代对象}` 生成键值对：

```python
square_by_number = {number: number ** 2 for number in numbers}
print(square_by_number)
```

如果多个元素生成相同的键，字典中只保留该键对应的最后一个值。

### 集合推导式

集合推导式用 `{表达式 for 元素 in 可迭代对象}` 生成集合。重复结果会自动合并，集合不保证显示顺序：

```python
remainders = {number % 3 for number in numbers}
print(remainders)
```

### 推导式中的循环变量作用范围

Python 3 中，列表、字典和集合推导式内部的循环变量不会泄漏到外层。它和普通 `for` 循环的变量作用范围不同：

```python
number = 100
squares = [number ** 2 for number in [1, 2, 3]]
print(number)  # 100
```

推导式内部的 `number` 用于当前推导式，不会覆盖外层的 `number`。

### 何时使用推导式

推导式适合一眼能读懂的单步转换或筛选。如果处理过程包含多层条件、复杂分支或多个副作用，使用普通 `for` 循环通常更清楚。

## 示例

下面从一组数字生成平方列表、偶数平方列表、数字到平方的字典，以及余数组合：

```python
numbers = [1, 2, 2, 3, 4]

squares = [number ** 2 for number in numbers]
even_squares = [number ** 2 for number in numbers if number % 2 == 0]
square_by_number = {number: number ** 2 for number in numbers}
remainders = {number % 3 for number in numbers}

print(squares)
print(even_squares)
print(square_by_number)
print(remainders)
```

列表保留原有顺序和重复元素；字典的键不会重复；集合会去重且不保证输出顺序。

## 小结（掌握范围）

- 能用列表推导式转换或筛选元素。
- 能用字典推导式生成键值对，用集合推导式生成去重结果。
- 知道推导式循环变量不会泄漏到外层作用域。
- 能判断简单操作使用推导式，复杂逻辑保留普通循环。
