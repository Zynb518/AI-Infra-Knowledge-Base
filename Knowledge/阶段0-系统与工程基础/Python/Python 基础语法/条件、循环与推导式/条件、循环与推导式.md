# 条件、循环与推导式

[返回 Python 基础语法](<../Python 基础语法.md>)

本主题复习如何用条件分支、循环和推导式表达重复或有选择的处理逻辑。

## 课程导航

1. [条件判断与布尔表达式](<./条件判断与布尔表达式.md>)

   学习 `if`、`elif`、`else` 分支，使用比较运算符和 `and`、`or`、`not` 组合条件，并了解常见值的真值判断。

2. [循环与循环控制](<./循环与循环控制.md>)

   学习用 `for` 遍历序列和字典（默认取键，也可用 `.items()` 取键值）、用 `range()` 生成整数序列、用 `while` 重复执行，并通过 `break` 和 `continue` 控制循环。

3. [列表、字典与集合推导式](<./列表、字典与集合推导式.md>)

   学习用推导式转换和筛选元素，创建列表、字典和集合，并理解推导式循环变量的作用范围。
