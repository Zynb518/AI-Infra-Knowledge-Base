# 循环与循环控制

## 引入

循环让同一段代码可以处理多个值，或在条件满足时重复执行。Python 常用 `for` 遍历序列，使用 `while` 根据条件重复；`break` 和 `continue` 可以改变循环的执行过程。

## 核心内容

### 用 `for` 遍历序列

`for` 会依次取出序列中的元素，并在每个元素上执行循环体：

```python
languages = ["Python", "Rust", "Go"]

for language in languages:
    print(language)
```

每轮循环中，`language` 会依次引用一个元素。列表、元组、字符串和字典等对象都可以用 `for` 遍历。

遍历字典时，直接使用 `for` 会依次得到键；`.items()` 可以同时得到键和值，`.values()` 则只遍历值：

```python
scores = {"语文": 90, "数学": 88}

for subject in scores:
    print(subject)

for subject, score in scores.items():
    print(f"{subject}：{score}")
```

第一段循环输出科目名称，第二段循环同时处理科目和分数。

和 `if` 一样，`for`、`while` 的缩进也不建立新的变量作用域。在同一模块或函数中，循环体里赋值的名称在循环后仍属于该模块或函数作用域；如果 `for` 遍历空序列，循环变量就不会被赋值。

### 用 `range()` 生成整数序列

`range(stop)` 生成从 `0` 开始、到 `stop` 之前结束的整数；`range(start, stop, step)` 可以指定起点、终点和步长：

```python
for number in range(1, 5):
    print(number)
```

这段代码依次处理 `1`、`2`、`3`、`4`。终点不包含在结果中。

### 用 `while` 按条件重复

只要 `while` 后面的条件为真，循环体就会继续执行。循环中的操作通常需要改变条件相关的值，确保循环最终可以结束：

```python
countdown = 3

while countdown > 0:
    print(countdown)
    countdown -= 1
```

每轮都将 `countdown` 减一；当它变为 `0` 时，条件不再成立，循环结束。

### 用 `break` 和 `continue` 控制循环

- `break` 立即结束当前循环。
- `continue` 跳过本轮剩余语句，直接开始下一轮。

```python
for number in range(1, 6):
    if number == 2:
        continue
    if number == 5:
        break
    print(number)
```

这里会跳过 `2`，并在遇到 `5` 时结束循环，所以输出 `1`、`3`、`4`。

## 示例

下面计算列表中的总分，并统计达到及格线的分数数量：

```python
scores = [78, 55, 92, 61]
total = 0
passed = 0

for score in scores:
    total += score
    if score >= 60:
        passed += 1

print(f"总分：{total}")
print(f"及格人数：{passed}")
```

循环变量 `score` 每轮取得一个分数；`total` 和 `passed` 在循环中累计，循环结束后可以继续使用。

## 小结（掌握范围）

- 能用 `for` 遍历列表、元组和字符串等序列。
- 能用 `range()` 生成整数序列，并理解终点不包含在结果中。
- 能用 `while` 根据条件重复执行，并更新相关变量使循环可以结束。
- 能使用 `break` 结束循环、使用 `continue` 跳过本轮剩余语句。
