# 字典与集合

## 引入

列表和元组按位置保存数据。需要通过名称查找数据时，可以用字典；需要保存不重复的值或比较两组成员时，可以用集合。

## 核心内容

### 字典：用键查找值

字典使用花括号保存 `键: 值` 对。可以通过键读取值；给已有键赋值会更新它，给新键赋值会添加一项：

```python
scores = {"语文": 90, "数学": 85}
print(scores["数学"])

scores["数学"] = 88
scores["英语"] = 92
print(scores)
```

键用于标识对应的值，不能像列表那样用 `0`、`1` 这样的顺序位置来取值。常见的键是字符串或数字；同一个键只能对应一个当前值。

用 `字典.get(键, 默认值)` 查询可选数据：键存在时返回对应值；键不存在时返回默认值，不会因为缺少该键而中断：

```python
email = {"name": "小林"}
print(email.get("address", "未填写"))
```

### 集合：保存不重复的值

集合使用花括号，元素重复时会自动合并。创建空集合要写 `set()`，因为 `{}` 表示空字典：

```python
languages = {"Python", "Rust", "Python"}
empty_set = set()
print(languages)
```

集合不按位置访问元素，也不保证元素的显示顺序；可用 `in` 判断成员，用 `add()` 添加元素，用 `discard()` 移除元素。重复添加不会增加重复项。

### 比较集合

集合可以用运算符比较两组元素：

| 运算  | 含义                   | 写法      |
| --- | -------------------- | ------- |
| 并集  | 任一集合中出现的元素           | a \| b  |
| 交集  | 同时出现在两个集合中的元素        | `a & b` |
| 差集  | 在 `a` 中、但不在 `b` 中的元素 | `a - b` |

## 示例

下面用字典保存学习记录，用集合找出两份清单的共同项和差异：

```python
record = {"name": "小林", "completed": 2}
record["completed"] = 3
record["next"] = "字典与集合"
print(record["completed"])
print(record.get("note", "暂无备注"))

planned = {"变量", "列表", "字典"}
reviewed = {"变量", "列表", "函数"}
print(planned & reviewed)
print(planned - reviewed)
print(planned | reviewed)
```

字典按键保存并查询值；集合运算得到新的成员组合。集合输出顺序可能变化，不要依赖它的显示顺序。

## 小结（掌握范围）

- 能用字典保存键值对，通过键查询，并添加或更新一项。
- 能用 `get()` 为可能缺失的键提供默认值。
- 能创建集合并理解它会去重，使用 `in`、`add()` 和 `discard()`。
- 能用 `|`、`&` 和 `-` 分别求并集、交集和差集。
