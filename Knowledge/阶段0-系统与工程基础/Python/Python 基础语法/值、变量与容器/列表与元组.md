# 列表与元组

## 引入

一个变量可以保存单个值；当需要按顺序保存多个值时，可以使用列表或元组。它们都能保存多个元素并按位置读取，主要区别是列表可以修改，元组创建后不能修改。

## 核心内容

### 创建列表和元组

列表使用方括号 `[]`，元组通常使用圆括号 `()`：

```python
colors = ["蓝", "绿", "红"]
point = (3, 5)
```

元组只有一个元素时，末尾的逗号不可省略：

```python
single = ("Python",)
```

`("Python")` 只是带括号的字符串，不是元组。

### 用索引读取元素

索引从 `0` 开始，负索引从末尾倒数，`-1` 表示最后一个元素：

```python
colors = ["蓝", "绿", "红"]
print(colors[0])   # 蓝
print(colors[-1])  # 红
```

列表和元组都可以用索引读取元素。访问不存在的位置会产生 `IndexError`。

### 用切片读取一段内容

切片写作 `序列[起点:终点]`，包含起点位置，不包含终点位置：

```python
colors = ["蓝", "绿", "红", "黄"]
print(colors[1:3])  # ['绿', '红']
print(colors[:2])   # ['蓝', '绿']
print(colors[2:])   # ['红', '黄']
```

省略起点表示从开头开始，省略终点表示取到末尾。列表切片得到新列表，元组切片得到元组结果。两者的切片都按**浅拷贝**理解：复制外层序列中的元素引用，不会递归复制元素内部的对象。

如果元素本身是可变对象，切片前后的序列会引用同一个对象。所以下例中，给 `selected` 追加元素不会改变 `source` 的外层列表；但通过 `selected[0]` 修改共享的内层列表，会同时反映在 `source` 中：

```python
source = [["a"], ["b"]]
selected = source[:1]

selected.append(["new"])
selected[0].append("shared")

print(source)    # [['a', 'shared'], ['b']]
print(selected)  # [['a', 'shared'], ['new']]
```

元组切片也只复制元素引用；元组自身不能替换元素，但如果某个元素是列表等可变对象，仍可以通过该引用修改对象内容。

### 修改列表，保留元组

列表可以通过索引改值，也可以用 `append()` 在末尾增加元素；元组不支持这些修改：

```python
colors = ["蓝", "绿"]
colors[0] = "紫"
colors.append("红")
print(colors)  # ['紫', '绿', '红']

point = (3, 5)
# point[0] = 4  # 元组不可修改，这行会报错
```

当一组数据需要增删改时用列表；当一组数据创建后应保持不变时，可以用元组。

### 查看长度和判断成员

`len()` 返回元素数量，`in` 判断某个值是否存在于序列中：

```python
colors = ["蓝", "绿", "红"]
print(len(colors))       # 3
print("绿" in colors)   # True
```

## 示例

下面用列表记录待办事项并追加一项，用元组记录一个固定坐标：

```python
tasks = ["复习变量", "复习类型"]
tasks.append("复习容器")

position = (12, 8)

print(f"任务数：{len(tasks)}")
print(f"第一个任务：{tasks[0]}")
print(f"后两项：{tasks[1:]}")
print(f"是否包含容器复习：{'复习容器' in tasks}")
print(f"坐标：({position[0]}, {position[1]})")
```

这里 `tasks` 会在 `append()` 后多出一个元素；`position` 保持原样。索引读取单个元素，切片读取一段元素。

## 小结（掌握范围）

- 能用 `[]` 创建列表、用 `()` 创建元组，并正确创建单元素元组。
- 能用正索引、负索引和切片读取列表或元组中的内容。
- 知道列表可通过索引和 `append()` 修改，元组创建后不可修改。
- 能使用 `len()` 获取元素数量，并用 `in` 判断成员。
