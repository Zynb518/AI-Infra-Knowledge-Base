# 变量、基本类型与运算

## 引入

Python 脚本会把文字、数字和计算结果保存在变量中，再用这些值完成处理。本课快速复习变量、常见基本类型、算术运算和格式化输出，为后续学习列表、字典等容器打基础。

## 核心内容

### 变量保存值

使用赋值语句 `名称 = 值`，把右侧的值交给左侧名称：

```python
course = "Python"
lessons = 4
```

`=` 表示赋值。Python 会根据赋给变量的值确定其类型，不需要先声明类型。名称区分大小写，例如 `lessons` 和 `Lessons` 是不同名称。

### 常见基本类型

| 类型 | 用途 | 示例 |
| --- | --- | --- |
| `int` | 整数 | `4` |
| `float` | 带小数的数 | `2.5` |
| `str` | 文本 | `"Python"` |
| `bool` | 真或假 | `True`、`False` |
| `NoneType` | 表示当前没有具体值 | `None` |

用 `type(变量)` 查看类型。要在输出中只显示类型名称，可以用 `type(变量).__name__`。

### 基础算术运算

| 运算符 | 含义 | 示例结果 |
| --- | --- | --- |
| `+`、`-` | 加、减 | `7 - 2` 得到 `5` |
| `*`、`/` | 乘、除 | `7 / 2` 得到 `3.5` |
| `//` | 向下取整除法 | `7 // 2` 得到 `3` |
| `%` | 取余数 | `7 % 2` 得到 `1` |
| `**` | 乘方 | `2 ** 3` 得到 `8` |

`/` 会执行普通除法；`//` 与 `%` 常搭配使用，可分别得到整除结果和余数。

### 格式化输出

f-string 在字符串前加 `f`，并用 `{}` 放入变量或表达式：

```python
course = "Python"
lessons = 4
print(f"{course} 本轮计划复习 {lessons} 个主题。")
```

## 示例

下面的小例子记录商品和数量，计算总价并检查几个值的类型：

```python
item = "笔记本"
quantity = 3
unit_price = 2.5
in_stock = True
remark = None

total = quantity * unit_price

print(f"商品：{item}，数量：{quantity}，总价：{total}")
print(f"单价类型：{type(unit_price).__name__}")
print(f"有库存吗：{in_stock}，备注：{remark}")
print(f"总价平分成两份：{total / 2}")
```

运行时会看到 f-string 把变量值插入文本；`unit_price` 和 `total` 的类型名称都是 `float`。

## 小结（掌握范围）

- 能用赋值语句创建变量，并理解 `=` 在这里表示赋值。
- 能识别 `int`、`float`、`str`、`bool` 和 `None`，并用 `type()` 查看类型。
- 能使用基础算术运算符完成简单计算。
- 能用 f-string 把变量和计算结果放进输出文本。
