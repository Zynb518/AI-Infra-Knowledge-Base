# 值、变量与容器

[返回 Python 基础语法](<../Python 基础语法.md>)

本主题从变量和值开始，逐步复习 Python 的常用内置类型和容器。

## 课程导航

1. [变量、基本类型与运算](<./变量、基本类型与运算.md>)

   学习用赋值语句创建变量，用 `type()` 查看 `int`、`float`、`str`、`bool` 和 `None`，并复习基础算术运算与 f-string。

2. [列表与元组](<./列表与元组.md>)

   学习用 `[]` 和 `()` 创建列表与元组，使用索引、切片、`len()` 和 `in` 读取内容，并理解列表可修改、元组不可修改。

3. [字典与集合](<./字典与集合.md>)

   学习用字典保存键值对并查询、添加和更新数据；用集合去重、判断成员，以及使用 `|`、`&`、`-` 做并集、交集和差集。

当前主题暂不设置课后实操；按课程导航顺序学习，收到你的要求后再补充实操。
