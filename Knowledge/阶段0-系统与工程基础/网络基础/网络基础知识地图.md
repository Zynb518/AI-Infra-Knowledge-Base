# 网络基础知识地图

> 面向 AI Infra 的网络基础子知识库入口。
>
> 本子知识库是仓库中所有网络知识的唯一正文归属，包括协议原理、Linux 网络实现、网络隔离、服务通信和网络故障诊断；其他子知识库只链接到这里，不重复维护网络内容。

## 推荐学习路径

```text
分层、封装与寻址
  → Ethernet、IP 与路由
  → UDP 与 TCP
  → DNS、HTTP、gRPC 与 TLS
  → Linux 网络实现
  → 负载均衡与服务治理
  → 性能分析与故障诊断
  → AI Infra 网络实验
```

## 一次网络排障应走完的链路

```text
用户症状
  ↓ 明确错误率、吞吐、连接数、平均延迟与尾延迟
应用层
  ↓ 检查 DNS / HTTP / gRPC / TLS / 超时与重试
传输层
  ↓ 检查 TCP 状态、重传、窗口、连接队列与 Socket buffer
网络层与链路层
  ↓ 检查地址、路由、MTU、丢包、网卡与物理链路
路径与对端
  ↓ 对照客户端、代理、负载均衡器、服务端和返回路径
根因与修复
  ↓ 抓包或指标验证、回归测试、记录边界条件
```

## 子知识库完成标准

- 能从 Ethernet、IP、TCP/UDP 到 HTTP/gRPC 解释一次请求的数据路径。
- 能根据地址、子网和路由表判断数据包的下一跳。
- 能解释 TCP 建连、断连、可靠传输、流量控制、拥塞控制和重传。
- 能解释 DNS、HTTP/1.1、HTTP/2、gRPC、SSE 与 TLS 的职责和主要取舍。
- 能用 `ip`、`ss`、`dig`、`tcpdump`、`iperf3` 等工具为判断提供证据。
- 能区分延迟、带宽、吞吐、并发、PPS、丢包和重传等指标。
- 能从客户端、连接、代理、服务端和路径五个层面排查服务超时。
- 能说明 RDMA、RoCE 与普通 TCP/IP 网络的基本差异及其在 AI Infra 中的位置。
